# 音乐试听 · 鲸鲨首领战（2026-11-10）

## 1. 任务边界

- 本轮只做 **BGM 试听稿**，不接线、不进 `assets/`、不改 `scripts/yinxiang.gd`、不改 `YinXiang.BGM_QU_MU`、不改任何测试或 gameplay 文件。
- 产物：LMMS 工程 + 44.1kHz/16bit/单声道循环 WAV + 本说明。
- 没有使用 `generative-music` / `audio-as-code` 两个 skill 的 Python 合成器，只借用其工作流：brief → 双参考风格表 → 音高世界 → 动机 → 编配 → 测量 → 试听。
- 参考只取“气质”，旋律、和声、节奏型全部原创；未采样、未引用原曲。

## 2. 听感 brief

- 场景：鲸鲨首领战，玩家在低频压迫中读招、躲避、找输出窗口。
- 气质：Subnautica 利维坦式的“看不见但很大”的深海压迫 + Shadow of the Colossus 巨兽战的“缓慢、沉重、仪式感”。
- 时长：24 小节循环，约 68.6 秒；可无缝回到开头。
- 听感关键词：D 弗里吉亚、次低频巨兽、声呐、心跳、鲸歌、铜管低音、不谐弦乐、开放收束。

## 3. 双参考风格表

| 参考 | 取什么 | 不取什么 |
| --- | --- | --- |
| Subnautica 利维坦压迫 | 20–80Hz 长音 pedal、稀疏正弦声呐 ping、长衰减尾音、慢和声移动、靠“安静中的巨大感”制造恐惧 | 不复制任何环境采样、生物叫声、原曲音色 |
| Shadow of the Colossus 巨兽战 | 80–90 BPM 慢速、自然小调/弗里吉亚、低音铜管式动机、低通战鼓、分层推进、开放式循环收束 | 不复制原曲旋律、鼓点、战斗主题 |

两首参考在本稿中统一为：

- 速度 84 BPM、4/4；
- 低频 pedal 贯穿，b2（Eb）作为弗里吉亚色彩；
- 打击乐稀疏但重，心跳/脚步优先于密集鼓组；
- 4 音动机反复回归，段落靠“加层”和“移位”推进；
- 结尾不解决到完满终止，而是开放五度 + 声呐余响，方便循环。

## 4. 音高世界

- 调式：D 弗里吉亚（D–Eb–F–G–A–Bb–C）。刻意避开 E 自然音与 C#，让 b2（Eb）始终是“巨兽阴影”。
- 主音区：D1–D5。D1/D2 负责体重，D4/D5 负责鲸歌与声呐。
- 和弦/音簇：
  - Dm：D–F–A；
  - bII：Eb（作为 D 上的 b2 色彩）；
  - Bb：Bb–D–F；
  - Gm：G–Bb–D；
  - Am：A–C–Bb（A 上的 b2 音簇）。
- 不谐弦乐使用小二度/大二度音簇：
  - D–Eb–F（D 段）；
  - Bb–C–D（Bb 段）；
  - G–A–Bb（G 段）；
  - A–Bb–C（A 段）。
- 所有持续声部都有明确音区，避免随机高音；没有需要“概率例外”的色彩音。

## 5. “巨影”动机与变形

动机：**D–F–Eb–D**，音级 **1–3–b2–1**，节奏 **2+1+1+4 拍**。

| 段落 | 出现方式 | 变形 |
| --- | --- | --- |
| 0–3 小节 | 声呐 ping 高音碎片：D5–F5–Eb5–D5 | 拆成短促回声，先“远远听到” |
| 4–11 小节 | 鲸歌完整陈述：D4–F4–Eb4–D4 | 第一次完整出现，慢起音、长释放 |
| 6–9 小节 | 鲸歌模进：F4–A4–G4–F4；A3–C4–Bb3–A3 | 向上移位、再落到属区 |
| 12–19 小节 | 铜管低音：每两小节一块，D2–F2–Eb2–D2 → Bb1–D2–C2–Bb1 → G1–Bb1–A1–G1 → A1–C2–Bb1–A1 | 低八度、节奏加重、和声根音移位 |
| 20–23 小节 | 高八度鲸歌：D5–F5–Eb5–D5 | 回归主题，但用高音和开放五度收束 |

## 6. 结构与编配

84 BPM，4/4，24 小节，每小节约 2.857 秒。

| 小节 | 时间 | 段落 | 内容 |
| --- | --- | --- | --- |
| 0–3 | 0:00.0–0:11.4 | 下潜 | D–C–Bb–A 逐小节下沉的 drone；D1/D2 长音；声呐 ping 预告动机 |
| 4–11 | 0:11.4–0:34.3 | 心跳 + 鲸歌 | 每小节 lub-dub 低鼓；鲸歌完整陈述、两次模进；低音从 D 移到 A/Bb 再回 A，推入高潮 |
| 12–19 | 0:34.3–0:57.1 | 铜管 + 不谐弦乐 | 四个两小节块：Dm → Bb → Gm → Am；铜管低音奏动机移位；D/Eb/F 等音簇弦乐；战鼓错位进入；12/16 小节块头重击 |
| 20–23 | 0:57.1–1:08.6 | 回环收束 | 高八度鲸歌回归；弦乐从 Dm 解决到 D 开放五度；心跳只留两下；声呐余响折回开头 |

编配（11 轨）：

1. 巨兽Sub：D1/D2 正弦长音；
2. 下潜Drone：锯齿+三角的滤波 drone；
3. 声呐Ping：正弦长衰减；
4. 心跳低鼓：`kick_soft01` 低通；
5. 战鼓低频：`tom_low01` 低通，C 段错位进入；
6. 鲸歌：三角+正弦，慢起音、长释放，带低八度影子；
7. 铜管低音：锯齿+方波+低八度，短起音、块状重音；
8. 铜管持续：根音+五度长音，撑住铜管墙体；
9. 不谐弦乐：双锯齿微失谐，C 段小二度/大二度音簇；
10. 高音弦乐：C 段高八度音簇，音量压低避免刺耳；
11. 高潮冲击：`kick_hard01` 低通，12/16/20 小节块头。

## 7. 制作与测量

### 7.1 LMMS 渲染

- 引擎：LMMS 1.2.2（`D:\LMMS\lmms.exe`）。
- 工程：`tools/yinyue/bgm_jing_sha.mmp`。
- 命令：`lmms render tools/yinyue/bgm_jing_sha.mmp -f wav -s 44100 -x 2`。
- 原始渲染：71.4275 秒（24 小节 + 1 小节尾音），44.1kHz 立体声 16bit；峰值 -2.818 dBFS；削波采样 0。
- 说明：LMMS 固定多渲染 1 小节尾音，正好用来把最后一小节的释放尾折回开头。所有末段音符释放已控制在 2.5 秒内，能落在这 2.857 秒尾音里。

### 7.2 Python `wave` 后处理

1. 取整段循环长度：24 小节 = 3,024,000 帧 = 68.571429 秒。
2. 把 LMMS 多出的 2.857 秒尾音折回开头（相加），让尾音参与下一轮循环。
3. 循环滑动均值去直流/次低频（0.2 秒窗，按周期信号计算），去掉 tripleoscillator 三角/锯齿层带来的 DC 和 5Hz 以下漂移；去后仍保持首尾周期连续。
4. 峰值归一化到 **-1.5 dBFS**。
5. 首尾各 5ms 线性淡入/淡出（220 个采样），避免硬切。

## 8. 试听重点

1. **0:00–0:11 下潜段**：D1/D2 是否“有体重但不糊”；声呐 ping 的 D5–F5–Eb5–D5 是否能听出动机预告。
2. **0:11–0:34 心跳+鲸歌段**：lub-dub 低鼓是否像心跳而不是普通底鼓；鲸歌在低鼓上面是否清楚；鲸歌长释放叠到下一句时是否自然。
3. **0:34–0:57 高潮段**：铜管低音的四个移位块是否能被辨认；D/Eb/F 音簇是否“压迫但不刺”；战鼓错位是否像巨兽脚步而不是杂乱鼓点。
4. **0:57–1:08 收束段**：高八度鲸歌回归是否成立；Dm → D 开放五度是否收住；声呐余响折回开头是否自然。
5. **循环缝**：在 1:08.57 接 0:00 循环播放，听是否有“断一下”或“突然进 ping”；本文件已做 5ms 淡入淡出与尾音折回，但 5ms 淡入淡出本身会有约 10ms 的轻微凹陷，属于预期。
6. **设备检查**：手机外放可能听不到 D1（36.7Hz），重点听 D2/D3 与 250–1000Hz 的鲸歌/弦乐；耳机/低音炮再检查 20–60Hz 是否过重。
