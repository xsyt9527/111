## 2. 统一视觉规范（Style Bible）

> 本节把参考方向里可复用的**通用画风**拆成参数：高饱和鱼体、深色粗描边、大色块平涂、硬边阴影、大眼萌、夸张剪影、小屏高可读。下面所有数值都是生成时的硬指标，比“像某个具体作品”更重要。不要提任何作品名，也不需要具体角色或界面。

### 2.1 线条

- 外轮廓：1024 画布上 **14–18px**；最终缩到 108px 后约 **1.5–2px**。
- 内部结构线：**6–8px**（鳍与身体分界、鳃线、嘴线）；不要每条鳍刺都描边。
- 描边颜色 = 填充色同色相压暗 35–45%，**不用纯黑**：
  - 橙红 `#FF6A3D` → 描边 `#8C2F16`
  - 青蓝 `#4AD8D0` → 描边 `#1C6E6A`
  - 深紫 `#5B4A86` → 描边 `#241B3D`
  - 深色/黑色鱼统一用深海墨蓝 `#101A26`
- 眼睛、獠牙、发光核心可用近黑 `#0B1220`，形成最高对比点。
- 发光器官（诱饵、灯笼、核心）画**实体外形 + 1–2px 浅色内描边**，但**不画外发光/光晕/射线**。

### 2.2 上色

- 每个材质最多 **3 个色阶**：底色、暗部（压暗 15–20%）、高光（提亮 20–30%）。
- 暗部硬边 + 2–3px 软过渡；高光用月牙形/椭圆硬边，一块主体 1–2 处。
- 允许沿身体方向轻微渐变（明度变化 ≤8%）；不允许喷枪式全图渐变。
- 鱼鳍：同色系提亮 15–25%；鳍膜 alpha 80–95%，不要羽毛状半透明边。
- 禁止：鳞片网格、皮肤噪点、写实反光、环境色反射、HDR 塑料高光。

### 2.3 光照与视角

- 统一光照：**左上主光，右下暗部**；所有素材同一方向。
- 视角：**纯侧视**（2D 纸片），鱼头朝右、尾朝左；只露一侧胸鳍和背鳍。
- 眼睛：占头长 22–28%，奶油白眼球 + 深墨蓝/黑瞳孔 + 1 个白色高光点（可加 1 个小副光点）。
- 表情：用眼形和嘴线表达，不画复杂拟人五官；坏笑、獠牙、怒眉可以有，但保持卡通。

### 2.4 比例与剪影

- 常规鱼：体长 : 体高 ≈ **2.2–3.2 : 1**。
- 细长鱼（剑鱼、旗鱼、电鳗）：**3.5–4.5 : 1**。
- 圆胖鱼（蜗牛鱼、河豚类）：**1.6–2.0 : 1**。
- 鲸鲨/首领：**2.6–3.6 : 1**，明显更宽厚。
- 嘴在画面最右侧边缘，尾鳍在最左侧，**不能裁切**。
- 每种鱼必须有 1 个「108px 还能认出来」的剪影特征：大嘴、长吻、帆鳍、发光诱饵、透明头罩、毒棘、九尾等。
- 同一鱼种的 3 个进化形态，**保留该鱼种的基础身体轮廓**，只在这个轮廓上做分支变化。

### 2.6 背景与前景的明度关系

- 背景整体比鱼体**暗 20–30%，饱和度低 10–20%**，保证鱼是画面最亮、最饱和的东西。
- 背景远层只用剪影，不描边；中层可用细描边；近层粗描边，形成空气透视。
- 背景中心（玩家常活动的 1280×720 区域）留大片开阔水，不堆高对比细节。

### 2.7 Rig 友好造型规范（新增，直接影响能否动起来）

骨骼动画不是逐帧换图，而是把**同一张图**用网格和权重弯折。以下规则比“好看”更重要：

1. **所有部件必须物理相连**：诱饵要有杆、灯笼要有柄、王冠要贴头、帆要连背、九尾要连臀；不能画漂浮的星星、光环、气泡、鬼火、碎屑。
2. **附属物之间留 ≥20px 透明间隙**：九尾、蛇发、多鳍、多触须不能交叉、不能贴在一起，否则网格权重会粘连，一动就撕。
3. **不要画得过细**：1024 画布上任何要参与弯曲的结构线/鳍条 ≥6px；1–2px 的细丝在变形后会断裂。
4. **静息姿态取中间值**：身体水平、脊柱直、尾巴自然向后伸直、鳍半展（约 45°，不要完全收拢也不要完全张开）、嘴闭合或微张 ≤10°。
5. **关节处不要有横切细节**：条纹、色块、装甲分界线不要正好落在颈、尾柄、下颌等活动关节上；否则弯曲时会出现“折断”感。
6. **透明材质降低内部对比**：史莱姆、幽灵、透明头罩内部只画少量低对比器官；高对比细节会在权重插值时抖动。
7. **只画一侧**：侧视图不要露出另一侧鳍/翅膀/眼睛；需要“双翼/多头”的形态，把另一侧画在身体后方并留出清晰分界。
8. **不做对称展开**：不要画正面展开的九尾、扇形全开的鳍；侧视下应按透视叠在身体后方，方便骨骼前后分层。

## 3. Rig 基准图硬规则（交付前逐条检查）

### 3.1 十条硬规则

| 编号 | 规则 | 不合格示例 |
|---|---|---|
| R1 | **单主体、单姿态、单层** | 一条鱼画了 2 个姿势、正侧混合、带分身 |
| R2 | **纯侧视，头朝右** | 3/4 视角、正面、头朝左 |
| R3 | **身体水平，脊柱直** | 身体弯成 C 形、S 形、头低尾高 |
| R4 | **尾巴直、向后伸** | 卷尾、打结、尾尖向前勾 |
| R5 | **鳍半展，不贴体、不交叉** | 鳍完全张开成扇、鳍叠在身体上、左右鳍交叉 |
| R6 | **嘴闭合或微张 ≤10°** | 大张嘴、下颌脱臼、獠牙外翻 |
| R7 | **所有附属物与身体相连** | 漂浮诱饵、悬浮王冠、断开的触须、碎裂星环 |
| R8 | **无动态特效** | 电弧、光晕、火花、星尘、气泡、速度线、残影、运动模糊 |
| R9 | **真透明、单主体、不裁切** | 白底、黑底、棋盘格、主体贴边、长吻被裁 |
| R10 | **关节处无横切细节、细结构 ≥6px** | 尾柄处一条粗横纹、1px 鳍条、装甲线正好压在颈部 |

### 3.2 画布与透明

- 鱼 / 进化 / 图标 / 特效 / 船 / 植物 / 气泡：**1024×1024 PNG**。
- 肉块：**512×512 PNG**。
- 背景：**4128×2304**；如果工具最大只能出 2048×1152，就出最高可用的 16:9，我方放大。
- 真透明（RGBA，alpha=0）。如果工具不能真透明：用纯洋红 `#FF00FF` 平涂背景，主体和描边上不能出现洋红反光；我方后期键色。
- 主体占画布 78–86%，四周留 ≥8% 透明边；长吻/尾鳍可接近边缘但不能贴边。

### 3.3 朝向

- 所有鱼：**头朝右、尾朝左**。
- 机器船：**朝左**，螺旋桨在右侧，炮塔炮口朝左。
- 武器/探照灯/鱼叉：**朝右**（游戏内按目标 `flip_h` 翻转）。
- 植物：竖直向上，根部在画布底边中央。
- 图标：符号居中，不指定朝向。

### 3.4 这些图会被直接退回

- 带 sprite sheet、多帧、分格、序列帧的图。
- 带任何文字、数字、logo、水印、边框、UI 的图。
- 背景不是透明（或不是洋红幕）的图。
- 主体被裁切、多个主体、带场景/地面/水花的图。
- 把光效画进基准图、导致骨骼一动就撕裂的图。
- 进化形态没有保留基础鱼轮廓、看起来像另一条鱼的图。

### 3.5 为什么不要帧（给 Gemini 的解释）

旧版靠“同一张图逐帧改尾巴”来动；AI 每次都会把鱼重画一遍，导致大小、配色、比例漂移。新版把“动”的工作交给 Godot 骨骼：只要基准图的**姿态中性、部件连接、关节干净**，程序就能稳定地弯尾巴、转头、张嘴、摆鳍，而且永远不漂移。所以本轮**画得“正”比画得“动”更重要**。

### 14.6 重要技术边界

- 插件自带 `--export-frames` 只导出**骨骼诊断线框图**（128×128、深色背景、绿线），不是成品帧；不能拿它当美术烘焙器。
- 需要继续喂给旧 `AnimatedSprite2D + SpriteFrames` 的地方，我方会另外写一个 **SubViewport 截帧烘焙脚本**（真实渲染器下逐帧截图、并集裁切、拼条）；或者直接把场景改成运行时 rig 节点。两条路都会在接入阶段按资产逐类决定。
- 因此 Gemini **绝对不需要**交帧；交单张中性图即可。只要单张图符合第 3 节，后续两条路都能用。
- 新美术先入 `assets/sucai`；`assets/sucai_classic` 暂时保留旧图用于回滚，验收后再决定是否合并。`scripts/hua_zhi.gd` 的画风切换逻辑本轮不动。
- 旧帧条、旧图在全部替换验收前**不删除**；先并存、再切换引用、最后清理。
