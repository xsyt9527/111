## 0. 使用方法（先读这三句）

1. **一次只生成一个素材**：一条 id 一张图，不要一次让 AI 拼 4 帧长条图或 sprite sheet。
2. **先生成第 1 帧，人工确认后再生成第 2~4 帧**：把已确认的第 1 帧作为参考图，逐帧生成，保持同画布、同构图、同锚点、同配色。
3. **图标与特效分开生成**：图标是单张 `<id>.png`；特效是 `<id>_zhen1.png` ~ `<id>_zhen4.png` 四张单帧，由我方脚本拼成 `<id>_4zhen.png`。

## 1. 统一规格（所有条目必须遵守）

| 项 | 规格 |
|---|---|
| 文件格式 | PNG，RGBA **真透明**；背景 alpha 全 0，不是白底、黑底、棋盘格或“假发光黑底” |
| 背景 | **无背景**：不画海水、海底、地面、环境雾、镜头光晕、地面投影 |
| 主体数量 | **单主体**：一张图只放一个技能/一个状态/一组特效；不画鱼本体、不画机器船本体（条目点名除外）；不把两个技能拼进一张图 |
| 朝向 | **朝右**：光束、鱼叉、冲刺、鱼头尖端朝右；爆炸/护盾/光环/声呐居中对称；运行时由代码旋转或翻转 |
| 帧数 | **4 帧一组**：第 1 帧静止/起始（可单独当图标或预览），第 2~4 帧动作递进 |
| 帧序 | f1 起始/静止 → f2 发展 → f3 峰值/命中 → f4 收束/消散；常驻光环 f4 必须能无缝接回 f1 |
| 每帧尺寸 | **每帧同尺寸**：默认 `1024×1024`；若生成器上限为 512，则整组统一 `512×512`，不得同组混用 |
| 构图稳定 | 同组 4 帧主体中心/光束起点位移 ≤2% 画布；不换姿势、不换视角、不换配色、不增减主体 |

| 锚点 | 画布中心 / 左中（光束起点）/ 底部中心（落水点、爆炸落点）/ 头部中心（眼睛、眩晕星）；每条单独标注 |

| 播放 | 新做特效统一 12 fps、4 帧单次约 0.33 s、`loop=0`；常驻光环 8 fps、`loop=1`；特殊时长另注 |
