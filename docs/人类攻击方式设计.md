### 0.2 现有两招的定位（作为轮换基线）

| 招式 | 现有判定 | 玩家应对 | 在轮换中的角色 |
| --- | --- | --- | --- |
| 渔网 | 预警圈半径 100（0.45 秒 × 300 速 ≈ 135px，原 150 跑不出去），延迟后命中即失控 1.5 秒 | 离开圈 | 控制 / 惩罚站桩 |
| 机械臂 | 0.6 秒伸向施放瞬间的位置，落点半径 90 | 走位离开落点 | 单点伤害 / 教玩家“看落点” |

现有两招的“圈 + 落点”语言已经占住了“地面圆形预警”。新增四招必须换几何、换颜色、换音效、换躲法，不能重复。

### 0.3 四招差异总表

| 招式 | 预警几何 | 主色 | 主效果 | 逼玩家做的动作 | 音效记忆点 |
| --- | --- | --- | --- | --- | --- |
| 深水炸弹 | 地面圆形圈 + 下坠炸弹 | 橙红 | 延迟范围爆发 | 离开落点、不要停 | 声呐“咚”+ 落水哨音 |
| 船锚横扫 | 船底扇形弧 | 琥珀黄 | 伤害 + 击退 | 拉开距离、绕到船后 | 铁链哗啦 + 低频横扫 |
| 探照灯扫描 | 移动光锥 | 青白 | 减速（无伤害） | 横移出光柱、别被追着照 | 电流嗡鸣 + 灯罩咔哒 |
| 鱼叉齐射 | 三条直线弹道 | 红白 | 远程单发伤害 | 垂直弹道横移 | 气阀“嗤”+ 金属钉入 |

**反同质化硬规则**：
1. 只有深水炸弹使用“地面圆形圈 → 延迟爆炸”。
2. 船锚的预警是**贴着船体的扇形**，不是地面圈；命中是即时横扫，不是延迟爆炸。
3. 探照灯是**持续移动的锥形**，没有地面落点，也不造成伤害。
4. 鱼叉是**线状弹道**，预警是三条细线，不是区域。
5. 四招的躲避动词分别是：离开圆、退出扇形、横移出锥、侧移躲线。任何一个招式的正确躲法不能同时适用于另一招。

### 0.4 通用出招状态机

```
降临 → 入场 1.0 秒（不攻击，给玩家看清血条）
     → 每 1.0 秒选一招 → 前摇 0.4~0.5 秒 → 判定/弹道 → 收招
     → 伤害窗口在下一拍伤害窗口前（约 1.4 秒）结束
```

- 同一时刻只允许一个**新伤害判定**开启；上一招的弹道/余辉可以残留到下一拍前摇期间，但必须在下一招伤害窗口开始前消失。
- 每招用一个“进行中”标志，`_process` 只更新当前招；未选中的招不跑计时。鱼叉这类多实例弹道用独立数组更新，不依赖“当前招”标志。
- 出招选择、同招冷却、阶段解锁统一放在 `_xuan_zhao()`，不要继续用 `_gong_ji_lun % 2` 的奇偶交替。
- 建议新增信号：`zhao_kai_shi(zhao_ming: StringName)`、`zhao_jie_shu(zhao_ming: StringName)`，给音效、镜头震动和测试断言用；`bei_ji_bai` 保持不变。

### 0.5 通用受击与闪避规则

| 情况 | 规则 |
| --- | --- |
| 玩家处于受伤无敌 `wudi` | 所有走 `shou_dao_yao_ji` 的伤害与控制被挡下；击退也挡下 |
| 玩家处于逆流闪避 `_ni_liu_sheng_yu > 0` | 同上，伤害/击退被挡下 |
| 玩家处于失控 `ZhangBen.zai_kong_zhi()` | 可以继续被伤害招命中；但轮换要执行“失控保护”（见 5.3），避免控制接必中 |
| 探照灯减速 | **不走** `shou_dao_yao_ji`，所以无敌帧不挡；逆流不“清除”减速，但可以用加速逃离光锥 |
| NPC 鱼 | 通过 `get_tree().get_nodes_in_group("yu_npc")` 取，调用其 `shou_dao_yao_ji`；单次爆炸最多结算 8 只，防止卡顿 |
| 鲸鲨 | 也是 `YuNpc`，可用同一接口；但只让深水炸弹和鱼叉在“优先目标”阶段主动打它，船锚/探照灯不碰它 |

## 一、深水炸弹

### 1.1 一句话定位

**逼玩家“别在同一个点上停超过半秒”**：用延迟范围爆发做区域封锁，同时允许玩家把炸弹引到鲸鲨或鱼群身上，形成“借刀杀人”的风险收益。

### 1.2 触发与选择逻辑

| 项目 | 设计 |
| --- | --- |
| 解锁阶段 | 血量低于 50% 后加入（第二阶段） |
| 基础权重 | 25 |
| 同招冷却 | 5.0 秒（1 秒一拍，约 5 拍内不再出） |
| 连发限制 | 不能连续两拍出；最近 4 拍内最多 2 次 |
| 距离修正 | 玩家在 0.8 秒内位移 <60 px（站桩）时权重 ×1.5；玩家持续高速移动时 ×0.8 |
| 目标选择 | 抛向**施放瞬间玩家当前位置**，不做预判；预判会让 0.5 秒预警变得不可躲 |
| 与鲸鲨的关系 | 若鲸鲨在玩家 250 px 内，权重 ×1.2：系统在“引诱玩家把炸弹带到鲸鲨附近”，但不强制 |
| 优先级 | 玩家刚被渔网控住时，本招权重临时归零（防止控制接必中） |

### 1.3 前摇与预警

| 项目 | 设计 |
| --- | --- |
| 前摇时长 | 0.5 秒（投掷动作 0.2 秒 + 炸弹下坠 0.3 秒），取 0.4~0.5 区间的上限 |
| 预警起点 | 施放瞬间，在玩家脚下画圈；圈不跟随玩家 |
| 预警形状 | 圆形，半径 120；外圈实线 + 内圈旋转虚线；圈心显示一个闪烁的小圆点 |
| 预警颜色 | 橙红 `Color(1.0, 0.38, 0.12)`；越接近爆炸，外圈 alpha 从 0.35 升到 0.85，内圈填充从 0.05 升到 0.18 |
| 炸弹表现 | 一颗带气泡尾迹的深水炸弹从船底抛向圈心，最后 0.1 秒下坠加速 |
| 音效 | 施放：低频声呐“咚”；下坠：短促落水哨音；爆炸前 0.1 秒：一声高频“嘀” |
| 可读性 | 圈半径 120 < 玩家 0.5 秒移动距离 150，玩家看到圈后立刻横移即可逃出；这是“反应得过来但很紧”的起步值 |

### 1.4 命中判定

| 项目 | 设计 |
| --- | --- |
| 形状 | 圆形 |
| 半径 | 120 px（爆炸）；预警圈同半径，所见即所得 |
| 生效时机 | 施放后 0.5 秒爆炸；爆炸判定持续 0.12 秒 |
| 穿透 | 不穿透：每个目标只结算一次；同一次爆炸不重复伤害 |
| 对玩家 | 在圈内且无无敌/逆流 → `wan_jia.shou_dao_yao_ji(1.0)` |
| 对 NPC | 圈内每只 `yu_npc` 结算一次，固定伤害 1.0（起步值）；死亡掉肉照常 |
| 对鲸鲨 | 圈内结算一次，固定伤害 0.8（起步值，待实机调） |
| 无敌帧 | 可挡；挡下后不扣血、不击退 |
| 逆流闪避 | 可挡；挡下后不扣血 |
| 边缘衰减 | 无衰减，圈内圈外二元判定；避免玩家误判“擦边没事” |

### 1.6 与现有系统的交互

| 系统 | 交互 |
| --- | --- |
| 玩家无敌帧 | 爆炸调用 `wan_jia.shou_dao_yao_ji`，无敌帧与逆流闪避原样生效；被挡下时不播放掉肉 |

### 1.7 美术帧规格

| 资源 | 类型 | 帧数 | 帧率 | 循环 | 用途 |
| --- | --- | --- | --- | --- | --- |
| `shen_shui_zha_dan_4zhen.png` | 横条 | 4 | 12 fps | 是 | 炸弹下坠 / 气泡尾迹 |
| `shen_shui_zha_dan_bao_6zhen.png` | 横条 | 6 | 18 fps | 否 | 爆炸水花与冲击环 |

- 源图：每帧 **1024×1024、纯黑底 `#000000`**；交付时另给去背透明横条（等宽单元格、逐帧 alpha 质心对齐）。
- 朝向：炸弹与爆炸都**无方向**；不要画屏幕方向，不要烘焙水底背景。
- 锚点：两套资源都以画面中心为锚点；炸弹在游戏内显示直径约 56 px，爆炸约 240 px。
- 屏幕位置：炸弹从船底（船体局部 `(0, +60)`）抛向世界坐标落点；爆炸在落点世界坐标播放，不挂在船身上。
- 透明度/发光：炸弹本体不透明；爆炸核心白 alpha 0.95、橙红边缘 alpha 0.7、外圈水花 alpha 0.35。爆炸的闪光层可用 Additive，但不要整帧加发光，避免黑底残留灰边。
- 逐帧内容建议：
  - 炸弹 4 帧：01 弹体直立、少量气泡；02 向一侧倾斜、气泡变多；03 向另一侧倾斜、尾迹拉长；04 接近落点、弹体略压缩。
  - 爆炸 6 帧：01 白橙闪光球；02 火球扩张；03 冲击环出现；04 水花与碎片四散；05 火球变暗、水花下落；06 余波与气泡收尾。

### 1.9 测试点

1. 施放瞬间预警圈圆心等于玩家当时的 `global_position`；玩家之后移动，圈心不跟随。
2. 玩家在 0.5 秒内横移 130 px 以上，爆炸后 `ZhangBen.dang_qian_ti_xing` 不变。
3. 玩家停在圈内，爆炸后只扣 1.0 点体型一次，不会按帧重复扣。
4. 玩家在爆炸瞬间处于 `wudi` 或逆流窗口，扣血为 0。
5. 圈内放 3 只 NPC 鱼，爆炸后最多结算 3 次伤害；爆炸结束后 1.0 秒时下一招已开始。

### 1.10 与其它招式的区分

深水炸弹是**唯一的地面圆形延迟爆炸**，核心动词是“离开圆”。它不追人、不击退、不减速，压力来自“这个地方接下来会炸”。船锚是贴船扇形、探照灯是移动光锥、鱼叉是直线弹道，三者的预警形状和躲法都与它不同。

## 二、船锚横扫

### 2.1 一句话定位

**逼玩家“别贴脸”**：船锚以船体为圆心扫出大弧线，近身命中造成伤害并击退，把玩家从船底赶到中距离，给远程招留出空间。

### 2.2 触发与选择逻辑

| 项目 | 设计 |
| --- | --- |
| 解锁阶段 | 血量低于 35% 后加入（第三阶段） |
| 基础权重 | 20 |
| 同招冷却 | 6.0 秒 |
| 连发限制 | 不能连续两拍出；最近 6 拍内最多 2 次 |
| 距离修正 | 玩家距船 <300 px 时权重 ×3；>450 px 时权重 ×0.2 |
| 方向选择 | 以船体为圆心，朝玩家所在的一侧扫；玩家在船正下方时随机左/右，但预警会明确显示 |
| 安全区 | 船体上方与船后（扇形未覆盖处）安全；鼓励玩家绕后 |
| 优先级 | 玩家刚被渔网控住时权重归零；玩家刚被本招命中后的下一拍，权重归零（防止连续击退锁死） |

### 2.3 前摇与预警

| 项目 | 设计 |
| --- | --- |
| 前摇时长 | 0.45 秒 |
| 预警形状 | 以船底为圆心的**扇形**：内半径 50、外半径 240、张角 150°；外弧虚线 + 扇形淡填充 |
| 预警颜色 | 琥珀黄 `Color(1.0, 0.72, 0.25)`；前摇末尾外弧亮度提高，填充 alpha 从 0.06 升到 0.16 |
| 动画提示 | 船侧舱门打开，铁链开始放出，锚头在扇形起点处可见 |
| 音效 | 铁链“哗啦”由弱到强，最后 0.1 秒一声低频“呼——”预示横扫 |
| 可读性 | 扇形边界清晰；玩家在船正下方时，向船后或向上游即可离开扇形。0.45 秒移动 135 px，足以从半径 240 的扇区边缘逃出，但贴脸时来不及 |

### 2.4 命中判定

| 项目 | 设计 |
| --- | --- |
| 形状 | 环形扇形（内半径 50，外半径 240，张角 150°） |
| 生效时机 | 前摇结束后的 0.35 秒横扫；每帧按角度推进，玩家在扇区内即命中一次 |

## 三、探照灯扫描

### 3.1 一句话定位

**逼玩家“别在光柱里停留”**：光柱左右扫过，照到就减速，不造成伤害；它用持续追踪压力打乱玩家的走位节奏，而不是直接扣血。

### 3.2 触发与选择逻辑

| 项目 | 设计 |
| --- | --- |
| 解锁阶段 | 血量低于 30% 后加入（第三阶段） |
| 基础权重 | 20 |
| 同招冷却 | 5.0 秒 |
| 连发限制 | 不能连续两拍出；最近 5 拍内最多 2 次 |
| 距离修正 | 玩家距船 >350 px 时权重 ×1.5（远程压制）；<120 px 时 ×0.5（近身有船锚） |
| 起始方向 | 从玩家所在的一侧开始扫，保证第一次扫过玩家附近；之后左右交替 |
| 优先级 | 玩家刚被本招照到后的下一拍，权重 ×0.5；玩家刚被其它招命中后，权重 ×1.2（用作“喘息招”，不叠伤害） |

| 项目 | 设计 |
| --- | --- |
| 前摇时长 | 0.4 秒 |

| 预警颜色 | 青白 `Color(0.55, 0.95, 1.0)`；预演线 alpha 0.25，正式光柱 alpha 0.55 |
| 动画提示 | 灯罩亮起、轻微闪烁；船体下方出现一圈水汽 |
| 音效 | 电流嗡鸣由低到高，前摇末尾一声灯罩“咔哒” |
| 扫描过程 | 前摇结束后 0.6 秒内，光柱从 -35° 扫到 +35°（相对正下方），左右交替；扫速恒定，不追玩家 |
| 可读性 | 光柱有明确边界和移动方向；玩家看到预演线后，向光柱外侧横移即可。0.4 秒移动 120 px，足以离开起始光柱 |

| 生效时机 | 扫描 0.6 秒内每 0.1 秒检测一次；玩家圆形碰撞体与光锥相交即视为“被照到” |
| 穿透 | 光锥穿透一切，不被鱼群/鲸鲨阻挡；这是“光”而不是弹道 |
| 主效果 | **减速**：被照到时移动速度 ×0.55（减速 45%）；离开光柱后效果再持续 0.4 秒 |
| 是否叠加 | 不叠加暴露增伤、不招鱼群、不破潜伏；一次只做“减速”这一件事 |

| 逆流闪避 | 不“清除”减速，但逆流的速度提升可以帮助玩家冲出光锥；这是它和伤害招的区别 |

| 连发限制 | 不能连续两拍出；最近 4 拍内最多 2 次 |
| 距离修正 | 玩家距船 >220 px 时权重 ×2；<120 px 时权重 ×0.3（近身交给船锚/机械臂） |
| 预判 | 每发鱼叉按“玩家当前位置 + 玩家速度 ×0.15 秒”取瞄准点；不追玩家实时位置，给侧移留空间 |
| 三发关系 | 三发以瞄准方向为中心，左右各偏 10°；三发不是同一线，形成一个小扇面，但每一发都是直线 |
| 优先级 | 玩家刚被渔网控住时权重归零；玩家刚被本招命中后的下一拍权重 ×0.5 |

### 4.3 前摇与预警

| 项目 | 设计 |
| --- | --- |
| 前摇时长 | 0.45 秒 |
| 预警形状 | 三条细直线，从船底三个发射口指向三个预判点；线宽 4 px，末端画一个小三角 |
| 预警颜色 | 红白 `Color(1.0, 0.45, 0.35)`；前摇前半段 alpha 0.25，后半段升到 0.6，并出现轻微闪烁 |
| 动画提示 | 三个发射口打开，鱼叉尖反光；船体轻微后坐 |
| 音效 | 气阀“嗤”一声 + 金属上膛“咔”；三发离弦时每发一声短促“咚” |
| 可读性 | 三条线在前摇期间固定不动，玩家可以清楚看到弹道；0.45 秒足够横移出线。三发之间有 0.1 秒间隔，但 i-frame 会挡住后续命中，实际最多吃一发 |

### 4.4 命中判定

| 项目 | 设计 |
| --- | --- |
| 形状 | 每条鱼叉一个圆形判定 |
| 半径 | 14 px |
| 速度/射程 | 1000 px/s；最大射程 650 px；存活约 0.65 秒（最后一发在 0.65 秒射出，约 1.3 秒消失，早于下一拍伤害窗口） |

### 4.9 测试点

1. 前摇 0.45 秒内能看到三条固定预警线；0.45 秒后第一发鱼叉出现。
2. 玩家侧移 100 px 后，三发全部落空，`ZhangBen.dang_qian_ti_xing` 不变。
3. 玩家站在弹道上，三发只造成一次 0.6 伤害（无敌帧挡下后两发）。
4. 鱼叉飞行 650 px 后自动消失，不会无限飞行。
5. 鱼叉穿过 NPC 鱼/鲸鲨时不造成伤害、不消失；玩家在 1.0 秒时进入下一拍出招。

### 4.10 与其它招式的区分

鱼叉是**唯一的多发直线弹道**，核心动词是“侧移躲线”。它没有地面圈、没有扇形、没有持续光锥；预警是三条细线，命中有飞行时间。它和深水炸弹都造成伤害，但深水炸弹是“延迟 + 范围 + 可引怪”，鱼叉是“即时 + 直线 + 只打玩家”。

## 五、出招轮换建议

### 5.1 权重、冷却与阶段解锁

| 阶段 | 血量区间 | 可用招式 | 基础权重 | 同招冷却 |
| --- | --- | --- | --- | --- |
| P0 入场 | 100% | 无 | — | 入场 1.0 秒不攻击，给玩家看清血条；之后严格每 1.0 秒出招 |
| P1 试探 | 100%~50% | 渔网、机械臂 | 渔网 50 / 机械臂 50 | 2 拍 |
| P2 加压 | 50%~35% | 渔网、机械臂、深水炸弹、鱼叉 | 20 / 20 / 30 / 30 | 3 秒 |
| P3 终局 | 35%~15% | 六招全开 | 渔网 15 / 机械臂 15 / 深水炸弹 20 / 鱼叉 20 / 船锚 15 / 探照灯 15 | 3 秒 |
| P4 濒死 | <15% | 六招全开，权重偏向伤害 | 渔网 10 / 机械臂 10 / 深水炸弹 25 / 鱼叉 25 / 船锚 20 / 探照灯 10 | 2.5 秒 |

- 阶段切换只在跨过阈值时播一次“船体抖动 + 警报”，不额外停表。
- P1 只教两招，玩家先学会“看圈”和“看落点”；P2 加入“离开圆”和“侧移躲线”；P3 再加入“拉开距离”和“横移出光锥”。一次只加一种新动词，符合首局渐进引导的思路。
- 权重是“相对值”，不需要总和 100；`_xuan_zhao()` 里按权重抽签即可。

### 5.2 1 秒一击下防止玩家被淹没的硬规则

| 规则 | 内容 |
| --- | --- |
| 不同招 | 不能连续两拍出同一招；最近 4 拍内同一招最多 2 次 |
| 伤害连发上限 | 不能连续 3 拍都是伤害招（机械臂/深水炸弹/船锚/鱼叉）；第 3 拍必须出渔网或探照灯 |
| 失控保护 | 玩家处于 `ZhangBen.zai_kong_zhi()` 时，下一拍**只能出探照灯**（无伤害）；若探照灯未解锁，则**跳过这一拍**。绝不让 1.5 秒失控接一发必中伤害 |
| 受击保护 | 玩家连续被命中 2 次后，下一拍权重强制转向探照灯或渔网；连续 3 次后强制探照灯 |
| 击退保护 | 船锚命中后的下一拍，深水炸弹权重归零；鱼叉命中后的下一拍，船锚权重归零 |
| 同招重抽 | 抽到与上一拍相同的招，重抽一次；仍相同则选当前权重最高的其它招 |
| 收招硬上限 | 任何招的**新伤害判定/弹道**必须在下一拍伤害窗口前结束（约 1.4 秒）；旧弹道可在 1.0~1.4 秒残留，但不得与下一招伤害窗口重叠 |
| 特效不占判定 | 爆炸/水花/光柱余辉可以跨拍，但碰撞与减速检测必须关闭 |

### 5.3 期望伤害预算（起步值，待实机调）

| 项目 | 起步假设 |
| --- | --- |
| 玩家 Lv.8 体型/血量 | 约 9 点 |
| 单次有效命中伤害 | 0.6~1.0，平均约 0.8 |
| 目标命中率 | 15%~25%（熟练玩家）；新手 30%~40% |
| 目标战斗时长 | 60~120 秒（360 血，咬弱点 ×3） |
| 目标承受命中数 | 7~10 次 |
| 折算 DPS | 约 0.06~0.13 点体型/秒 |
| 调参顺序 | 先降伤害，再降权重，最后才考虑拉长 1 秒间隔；1 秒节拍是拍板口径，不轻易动 |

> 如果实机发现玩家“被四招淹没”，优先检查：①是否同时存在两个伤害判定；②失控保护是否生效；③深水炸弹/船锚是否在玩家失控时仍然出招。不要先加长前摇，0.4~0.5 秒是“可躲”的底线。

### 5.4 与“先攻击鲸鲨”的衔接

- 机器船降临后的前 8~10 秒，`dang_qian_mu_biao` 指向鲸鲨：只用**鱼叉**和**深水炸弹**打鲸鲨，不用渔网/机械臂/船锚/探照灯。
- 这段窗口是玩家的观察期：能看到鱼叉弹道和炸弹圈，但落点在鲸鲨附近，玩家被卷入仍会受伤（预警照常显示）。
- 玩家主动咬船一口，机器船立即把目标切回玩家（仇恨转移），奖励“趁人机互斗偷输出”。
- 鲸鲨死亡/退场，或 10 秒计时结束，目标切回玩家；切换时播一次短警报，不额外停招。
- 实现上建议在 `JiQiChuan` 增加 `mu_biao_jing_sha` 引用与 `dang_qian_mu_biao` 枚举；由 `Main` 在生成时注入鲸鲨，船不靠组名查找。

### 5.5 推荐的首版实装顺序

1. 先把现有渔网/机械臂压缩到 0.45~0.5 秒前摇、1 秒间隔，跑通基础节拍。
2. 接深水炸弹（复用现有 `_draw()` 圆圈语言，改动最小）。
3. 接鱼叉（直线弹道 + 对象池，验证多发与无敌帧）。
4. 接船锚（扇形判定 + `Yu.tui_kai` 击退接口）。
5. 接探照灯（光锥 + `Yu.jia_wai_bu_jian_su` 减速接口）。
6. 最后接权重表、阶段解锁、失控保护与“先打鲸鲨”目标切换。

## 六、额外候选（不实装，仅供以后）

### 6.1 螺旋桨尾流

- 机器船横向移动时，船尾留下一道持续 2 秒的湍流带；玩家穿过时被推向下游并轻微减速。
- 定位是“惩罚贴船尾跟游”，和船锚的“近身击退”不同：尾流是**移动路径**上的持续区域，不是瞬时扇形。
- 可以做成 4 帧循环的水流贴图，沿船尾路径铺 3~5 段，透明度递减。
- 风险：机器船本来就在慢速跟随，尾流容易变成“全程地面减速带”，需要限制为“船速 >60 px/s 时才留”。

### 6.2 漏油污染

- 船体受损后在原地漏出油斑，油斑半径 100，持续 5 秒；玩家进入后移动速度 ×0.7、屏幕轻微变暗。
- 定位是“污染战场”，逼玩家绕开船底；和探照灯的瞬时减速不同，油斑是**提前布置的持久区域**。
- 油斑可以被深水炸弹点燃（如果以后有火系）造成范围伤害；首版不做联动，避免系统耦合。
- 风险：油斑与深水炸弹圈都是地面圆形，容易和“圈→炸”同质化；必须用深色油面和气泡区分，且不爆炸。

### 6.3 声呐锁定

- 船体每 3 秒发一次声呐脉冲，扩圈扫过全屏；被扫到的玩家获得“锁定”标记 3 秒。
- 锁定期间，下一次鱼叉/深水炸弹的预判提前量从 0.15 秒提高到 0.4 秒，或预警圈缩小 20%。
- 定位是“逼玩家在脉冲时找掩体/停止移动”，把“站桩惩罚”做成一个可读的节奏点。
- 风险：全屏脉冲如果不可躲，会变成纯数值压制；需要设计“贴近船体/躲到鲸鲨背后”的规避方式，否则不做。

### 6.4 投饲机诱饵

- 船体向水面抛撒饲料，形成一个半径 180 的诱饵区，持续 4 秒；周围 NPC 鱼被吸引过来抢食。
- 定位是用“鱼群拥堵”干扰玩家走位，和“招来鱼群”的探照灯备选同源，但诱饵是**主动布置**而不是光照触发。
- 鱼群密度上升会让玩家更容易被撞、也更容易捕食，形成双向风险收益。
- 风险：现有 NPC 索敌/鱼群逻辑不建议为单个招式大改；首版只做视觉诱饵、不真正改 AI，避免影响生态。

### 6.5 拖网收口

- 船体放出两张拖网，从屏幕左右两侧向中间收拢，持续 3 秒；网线本身不伤害，但会把玩家往中间推。
- 定位是“压缩战场”，和空间收缩的终局主题一致；适合放在 P4 濒死阶段作为一次大招。
- 需要独立的“网墙”节点与推挤逻辑，不能复用渔网的单圈判定；实现成本高于本文四招。
- 风险：与地图边界、鲸鲨、NPC 的推挤叠加时容易把玩家卡进碰撞体；首版不做，等空间收缩系统稳定后再评估。

| 朝向 | 默认朝右；无方向资源在文件名/文档中注明；需要左右版本时用 `flip_h`，不要整条倒放 |
| 锚点 | 按各招 1.7/2.7/3.7/4.7 的锚点表设置；锚点错误会导致旋转/摆动位置偏移 |

| 循环 | 待机/飞行/光锥循环；爆炸/发射/横扫一次性，播完停最后一帧或 `queue_free` |
