# 进化专属技模块开发契约（2026-11-09）

> 给并行开发者的唯一说明书。先读完再动手；与本文件冲突的直觉一律以本文件为准。
> 主框架：`scripts/zhuan_shu_ku.gd`；模块目录：`scripts/zhuan_shu_ku/<yu_zhong>.gd`。

## 0. 一句话分工

剩余 36 条进化专属技 = 6 鱼种 × 3 分支 ×（1 主动 + 1 被动）。
**一个鱼种一个模块文件**，谁实现谁只改自己的文件；框架按技能 id 分派，
`yu.gd` / `yu_npc.gd` 只保留通用钩子，不再为每条技能加 match 分支。
6 个鱼种可以同时开发，文件零重叠。

## 1. 文件所有权（硬边界）

允许新建 / 修改（**只允许**这些）：

| 路径 | 说明 |
|---|---|
| `scripts/zhuan_shu_ku/<yu_zhong>.gd` | 你负责的鱼种模块（已存在占位实现，替换内容） |

## 2. 模块接口（照抄，只改常量与函数体）

```gdscript
extends RefCounted
# <鱼种名>（<yu_zhong>）专属技模块——3 分支 ×（1 主动 + 1 被动）
# 契约见 docs/专属技模块_开发契约.md

const ZHU_DONG_IDS: Array[StringName] = [&"你的主动1", &"你的主动2", &"你的主动3"]
const BEI_DONG_IDS: Array[StringName] = [&"你的被动1", &"你的被动2", &"你的被动3"]

static func guan_zhu_dong(bian_hao: StringName) -> bool:
	return ZHU_DONG_IDS.has(bian_hao)

static func zhu_dong_ids() -> Array[StringName]:
	return ZHU_DONG_IDS

static func bei_dong_ids() -> Array[StringName]:
	return BEI_DONG_IDS

static func shi_fang(yu, neng: NengLi, dang: int) -> bool:
	# 主动释放：返回 true 才扣冷却/播音效；false = 空放（条件不足）
	return false

static func geng_xin(yu, neng: NengLi, delta: float) -> void:
	# 每帧：只对「已装备」的技能调用（框架已过滤）；主动/被动都可能进来，
	# 用 neng.shi_zhu_dong() 区分。持续效果、召唤物、节拍都写这里。
	pass

static func shi_jian(yu, neng: NengLi, jian: StringName, shu_ju: Dictionary) -> bool:
	# 事件钩子：返回 true = 事件被吃掉（主流程立刻 return）
	return false

static func wen(yu, neng: NengLi, jian: StringName, shu_ju: Dictionary) -> float:
	# 数值查询：返回倍率；没装备时框架直接不调用，默认 1.0
	return 1.0
```

规则：
- 技能数值**一律从 `neng` 读**（`neng.dang_zhi(&"shu_zhi", dang)` / `neng.shu_zhi` /
  `neng.chi_xu` / `neng.ban_jing`），模块里只允许放行为常量（如节拍、射线宽度）；
- 模块持久的每玩家状态用 `yu.get_meta(&"zs_<id>_<字段>")` / `yu.set_meta(...)`，
  不要往 `Yu` 加成员变量（那要改 yu.gd）；
- 召唤物 / 临时节点挂到 `yu.get_parent()`（场景层），用 `queue_free` 或计时自毁；
- 所有 `get_nodes_in_group("yu_npc")` 遍历必须跳过 `si_le` 与无效实例；
- 首领（`shi_boss == true`）免疫六状态（`jia_zhuang_tai` 内部已挡）；“无视防御”类对首领减半
  （模块里自己判断 `shi_boss` 后乘 0.5）。

## 3. 框架分派语义（已实装，不要重复实现）

| 入口 | 何时调 | 关键约定 |
|---|---|---|
| `ZhuanshuKu.shi_fang(yu, neng, dang)` | 玩家按技能按钮，`Yu.shi_fang_zhu_dong` 的 `match` 默认分支 | 只有 `guan_zhu_dong` 命中的模块接；返回 true 才扣冷却 |
| `ZhuanshuKu.geng_xin(yu, delta)` | `Yu._process` → `_geng_xin_zhuan_shu` 每帧一次 | 只对**已装备**技能调用（主动看主动槽，被动看叠层） |
| `ZhuanshuKu.shi_jian(yu, jian, shu_ju)` | 主流程事件点 | 返回 true = 事件被吃掉 |
| `ZhuanshuKu.wen(yu, jian, shu_ju)` | 主流程数值点 | 所有已装备技能的返回值**连乘**；一个没装 = 1.0 |

## 4. 主流程钩子总表（目前已接通的全部）

### 4.1 事件 `shi_jian`

| `jian` | 触发点 | `shu_ju` 键 | 返回 true 的后果 |
|---|---|---|---|
| `&"yao_zhong"` | 玩家咬击结算完、扣目标血之后 | `mu`(目标)、`bu`(部位字符串)、`shang_hai`(最终伤害) | 返回值暂未使用（只做附加效果，如吸血/上状态） |
| `&"bei_yao"` | 玩家被咬/被撞，所有减伤算完、扣血之前 | `lai_yuan`(攻击者)、`shang_hai`、`bu` | **整口免伤**：主流程跳过 `_shoushang` 直接 return（破隐仍然执行）。适合闪避类被动；模块自己播特效、扣内部 CD |

### 4.2 数值 `wen`（返回倍率）

| `jian` | 用途 | `shu_ju` 键 | 乘在哪 |
|---|---|---|---|
| `&"leng_que_bei"` | 主动冷却倍率（0.85 = -15%） | `neng`(当前施放技能) | 施放成功后写入的冷却 |
| `&"yao_shang_bei"` | 玩家咬伤倍率 | `mu`、`bu` | 咬击最终伤害（致命区 ×3 之后） |
| `&"shou_shang_bei"` | 玩家受伤倍率（0.75 = -25%） | `lai_yuan`、`shang_hai`、`bu` | 受击最终伤害（所有旧减伤之后、扣血之前） |
| `&"su_du_bei"` | 玩家游速倍率 | `{}` | `_ti_xing_su_du_bi()` 的返回值 |
| `&"tun_men_kan"` | 吞噬门槛的“有效体型”倍率 | `mu`(目标) | 整吞门槛与致命区整吞判定 |
| `&"gan_zhi_bei"` | NPC 看玩家的感知倍率（0.75 = 更难发现） | `{}` | 每条 NPC 的玩家感知半径 |

需要新钩子 → 在报告中提出，不要自己改主流程。

## 6. 数据规范

### 6.1 技能 `.tres`（`data/nengli/<id>.tres`）

照 `data/nengli/lei_bao_zhao_huan.tres` 抄格式。硬性校验（`ce_shu_ju` 会跑）：

- `bian_hao` = 文件名；全库唯一
- `ming_zi` / `miao_shu` / `lai_yuan` 非空；`miao_shu` ≤ 110 字符
- `suoshu_xing_tai` = 你鱼种的 3 个进化形态 id 之一（主动/被动按分支对应）
- `lei_xing`：主动 `0`，被动 `1`
- `zui_da_dang = 1`（专属技单档，不可升档/叠层）
- 主动：`leng_que > 0`、`shu_zhi > 0`；被动：`shu_zhi > 0`
  （被动没有数值型主效果时，把“内部 CD 秒数”或“加成百分比”写进 `shu_zhi`，模块按语义读）
- 所有数值非负；档位表 `dang_biao` 留空
- 召唤/隐身/位移类在 `lei_bie` 打标签：`&"zhao_huan"` / `&"yin_shen"` / `&"wei_yi"` /
  `&"dian_xi"` / `&"dan_dao"`；不涉及的留空
- `tu_biao` 留空（36 条专属技暂无图标，`ce_shu_ju` 允许专属技无图）

### 6.2 进化形态槽位（`data/jinhua/<form>.tres`）

只加两行（其余字段不动、`load_steps` +2）：

```
[ext_resource type="Resource" path="res://data/nengli/<主动id>.tres" id="4_zhuan_shu_zhu_dong"]
[ext_resource type="Resource" path="res://data/nengli/<被动id>.tres" id="5_zhuan_shu_bei_dong"]
...
zhuan_shu_zhu_dong = ExtResource("4_zhuan_shu_zhu_dong")
zhuan_shu_bei_dong = ExtResource("5_zhuan_shu_bei_dong")
```

注意：若该形态原本没有 ext_resource 4/5，`load_steps` 从 3 加到 5；若已有其它 4/5 编号则顺延，
但不要动原有资源行。改完必须能被 `load()` 加载（自测里断言两条槽位非空）。
