## 五、受伤掉肉（本次新增玩法）

策划案 8.1「受伤掉肉」与 8.4「鱼肉」的首次落地：

- 玩家受伤（`_shoushang()`）且没有死亡时，在周围 46~58px 随机方向掉 **2 块**鱼肉（`DIAO_ROU_SHU`）。
- 受伤扣**当前体型（血量）**，不扣等级上限（2026-10-28 插课修订，下文「第五章补充」）；身体变小与掉血是同一个动作。
- 鱼肉挂在场景层，不跟玩家移动/缩放；随机漂出去、12 秒后淡出。
- 掉落后 **0.4 秒保护期**内不可吃，防止受伤者原地瞬间吃回；之后玩家和 NPC 都能吃。
- 玩家吃一块 **+1 经验**（`KeChiWu.jing_yan` 的默认值）——饥饿条还没做，先临时映射成经验；TASK-013 改成恢复饥饿。
- NPC 吃鱼肉只清场，不加经验（NPC 没有成长系统）；"任何鱼可进食"先做到这一层。
- 物理层：鱼肉 `collision_layer=4`、`collision_mask=0`；玩家/NPC 新增 `RouQu`，`collision_mask=4`，与鱼鱼判定的 layer 2 完全分开。
- 检测方式：每帧 `get_overlapping_areas()`，因为鱼肉 0.4 秒后才可吃，`area_entered` 只发一次，满足不了"进入后状态才变"。
- 受伤信号在物理查询刷新期触发，掉落时 `add_child` 必须 `call_deferred`，否则引擎报 `Can't change this state while flushing queries`。

### 补充（2026-10-28 晚）：受伤改扣当前体型 + 可吃红光

- 账本从「等级=体型」拆成两层：`deng_ji` 是**体型上限**（只升不降，上限 = 等级 + 1），`dang_qian_ti_xing` 是**当前体型 = 血量**。

## 六、可食用植物（海草 / 珊瑚）

策划案第十章「可食用植物」的首次落地——把原来只是背景装饰的海草/珊瑚变成**体型来源之一**：
