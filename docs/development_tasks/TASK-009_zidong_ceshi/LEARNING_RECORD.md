## 本课新概念

- SceneTree 测试运行器：`extends SceneTree` + `_initialize()` 借引擎跑代码，不加载游戏场景
- `assert_eq` 失败计数 + `quit(退出码)`：失败被记账而非爆炸；0/非 0 是门禁唯一语言
- 裸 `assert()` 挂死：断言失败当场中断脚本 → quit 永不执行 → 进程永挂
- 测试独立性：`load().new()` 每用例干净起跑线，单跑/全跑/换序一致
- 测试夹具 + 红测：校验器必须被已知坏数据验证；坏卡落 `tests/huai_ka.tres`（三分工第 5 验）
- `DirAccess` 数据遍历：加卡自动守护，拼错键当场现形
- 场景模式 vs `--script` 模式：Autoload 加载差异 → 集成测试起真场景
- 假绿三张脸：断言内部 SCRIPT ERROR 不计入 / 解析失败场景空跑 / 退出码 0 掩盖非致命错误
- 门禁三重把关：退出码 + ERROR 筛查 + Results 收卷行；门禁自己也要红测
- 资源卫生：不入树实例谁创建谁 `free()`（「谁常驻谁负责复位」的资源版）
