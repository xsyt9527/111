## 本课新概念

- **Autoload 全局单例**：project.godot [autoload] 注册，root 直下与场景平级；先于一切场景 _ready 就绪、切场景不销毁、任意脚本按名直呼
- **账本模式**：唯一所有者（jing_yan/deng_ji 只账本可写）+ 唯一入口（jia_jing_yan）+ 信号广播（sheng_ji / jing_yan_bian_hua）——账本不认识任何场景节点
- **CanvasLayer**：树上是孩子（随场景生灭）、画布上独立（不继承 Node2D 变换，钉死屏幕坐标）——"挂在哪=生命周期，怎么画=渲染"两维度
- **ProgressBar**：max_value/value 两值驱动进度条，适合经验/血量条
- **本级经验制**：升级扣除已用阈值（jing_yan -= yuzhi），从 0 重攒——非累计总分
- **信号多方订阅**：同一 sheng_ji 信号玩家与 UI 各自连接互不干扰——第 6 课弹窗第三家照抄
