## 本课新概念

- **输入层与运动层分离**：摇杆只出口径 `fang_xiang`，转向和速度由鱼按体型自己算
- **朝向角 `dang_qian_jiao`**：点可瞬间改，朝向只能按步长拧过去
- **转向速率与体型成反比**：`zhuanxiang_ji_su / tixing`，大鱼笨重
- **吞噬门槛带**：`≥ 对方 ×1.1` 整吞；`1/1.1 ~ 1.1` 中间带无事发生（咬击留给 TASK-012）
- **体型即血量**：`tixing` 同时是体积、吞噬资格、生命值；受伤 ×0.85，跌破 0.5 死亡
- **退役一条链路**：字段 → 信号 → 场景/脚本，三层一起删才算真退役
