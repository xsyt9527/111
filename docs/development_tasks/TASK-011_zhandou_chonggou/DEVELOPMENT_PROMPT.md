## 一、任务目标

九课做出来的是一台"点哪游哪 + 三选一"的机器；策划案要的是"摇杆 + 咬小再吃 + 体型即血量"。本课是重构的第一刀，只改三件事，其余全留着：

1. **移动**：点击目标点 → 虚拟摇杆 + 转向速率（大鱼笨重）
2. **吞噬**：严格大于 → 体型 ≥ 对方 ×1.1 才能整吞
3. **生命**：独立血条 → 体型即血量（受伤掉体型，体型跌破 0.5 死亡）

经验、升级、三选一**本课暂留**——一次只动一层，测试才守得住。TASK-014 再换成「吃谁得谁」。

### 完成后可观察结果

- 左下角摇杆拖动，鱼朝对应方向游；松手减速停止
- 同体型的鱼吃不掉也伤不到（中间带留给下一课咬击）
- 撞大一次鱼小一圈，血条没了，体型数字在动
- `tests/pao_pi.bat` 六步全绿

## 二、四步实现

### step-01 虚拟摇杆 + 转向模型

`scenes/YaoGan.tscn`（CanvasLayer：底板 + 摇杆头）+ `scripts/yao_gan.gd`：拖动限幅、归一化方向、松手归零。`main.gd` 挂载并每帧读取方向。`yu.gd`：删除 `mubiao_dian`，新增朝向角与 `zhuanxiang_sudu`（4.0 / tixing），沿朝向前进。

### step-02 吞噬门槛 ×1.1

`TUN_CHI_BEI_LV := 1.1`：嘴圈 ≥1.1 才吞；伤区 ×1.1 > 我才伤。中间带本课无事发生。

### step-03 体型即血量 + 体型显示 + 死亡判定

`_shoushang()` → `tixing *= 0.85` + 缩小 tween；`tixing < 0.5` → 结算。删除 `xue_liang`/`zuida_xue`/血条信号；Main 移除血条、加体型显示。

### step-04 测试更新与全量回归

新增 `tests/ce_yao_gan.gd`（归一化/限幅/零输入）；改 `tests/ce_panding.gd`（门槛/掉体型/死亡/中间带）；`pao_pi.bat` 加一步；F5 全量回归。
