# TASK-029 范围提案：主动技能栏自适应布局与手动攻击键

- 任务版本: v1
- 基线提交: `f27ae56893aed50db99ca6572659966bbca09b27`
- 来源需求（用户 2026-11-14 原文）:
  - 「还有主动技能太多会超出屏幕，这是个问题」
  - 「我在想要不要加给攻击键」

## 一、要解决的问题

1. **技能栏溢出**：`scripts/neng_li_ui.gd` 的主动技能按钮是单列竖排，`AN_NIU_KUAN=210`、`AN_NIU_GAO=64`、`AN_NIU_JIAN_JU=8`、`DI_BU_Y=680`，每多一个按钮 y 上移 72px。`ZhangBen.zhu_dong_zu` 没有数量上限，装备第 9 个主动时按钮 y = 680 − 64 − 72×8 = −32，直接跑出 720 高屏幕；第 8 个也已压到 y=40，贴近顶边。目前局内 10+ 主动并非不可能（三选一每次都能选主动），所以表现为「越往后越往屏幕外长」。
2. **缺少手动攻击入口**：当前咬击只有自动咬（`Yu.zi_dong_yao_ji = true`，`_process` 冷却到 0 自动 `_chang_shi_yao_ji()`）。用户在犹豫要不要加攻击键：加了操作感更强、能主动挑目标；但也可能和自动咬重复、增加误触。

## 二、本任务做什么

### step-01 技能栏自适应布局（`scripts/neng_li_ui.gd`）

- 抽出纯函数 `ji_neng_bu_ju(shu, shi_kou) -> Array[Dictionary]`，输入「主动数量 + 视口尺寸」，输出每个按钮的 `position` 与 `size`，不碰节点。布局规则：
  - 每列最多 5 个（`MEI_LIE_ZUI_DUO := 5`），列数 `clampi(ceili(shu / 5.0), 1, 4)`。
  - 第 0 个在右下角（右缘 1250、下缘 680），同一列自下而上排；排满一列后向左开新列。
  - 行高在数量多时压缩：1~5 个 72px（按钮高 64），6~10 个 60px（按钮高 52），11~20 个 52px（按钮高 44）；按钮宽按列数 210 / 210 / 168 / 132。
  - 摇杆换到右手侧（`yao_gan_ce == "you"`）时整组镜像到左缘 30，`BeiDongLabel` 同步。
- `_tong_bu_an_niu` 只负责按纯函数结果摆节点；技能数或摇杆侧变化才重建，`_process` 不重建。
- 长按范围判定（`AN_XIA_FAN_WEI`）与冷却变暗逻辑跟随新尺寸，不改交互语义。

### step-02 手动攻击键（`scripts/neng_li_ui.gd` + `scripts/yu.gd`）

- 推荐方案（默认按此实现）：**右下角常驻「咬」按钮**，96×96 圆形（`Button` + 圆形 `StyleBoxFlat`，代码生成，不改 `Main.tscn`），右缘 1250、下缘 680；技能组整体让到按钮左侧上方重新排布。
- 点击调 `Yu.yao_ji_shou_dong() -> bool`：
  - 冷却中（`_yao_ji_leng_que > 0`）、冲撞中（`_chong_zhuang_sheng_yu > 0`）、失控（`ZhangBen.kong_zhi > 0`）、九图/船演出期间：返回 `false`，不结算。
  - 调既有 `_chang_shi_yao_ji()`；空挥（`_yao_ji_mu_biao()` 返回 null）返回 `false` 且**不进冷却**；咬到目标返回 `true`，冷却由 `_chang_shi_yao_ji` 内部照常设置——手动与自动**共用同一把冷却尺**，不存在双入口重复结算。
  - 自动咬默认 `zi_dong_yao_ji = true` 保持不变：攻击键是补充入口，不是替换。
- 按钮反馈：文本「咬」+ 冷却剩余（如「咬 0.8s」），冷却中 `modulate` 变暗，就绪恢复；`NengLiUI` 层在演出期间被 `Main._qie_huan_hud(false)` 隐藏时按钮一并隐藏。
- 摇杆换右手侧时攻击键与技能组镜像到左下。

### step-03 测试与文档

- `tests/ce_panding.gd`：布局纯函数断言（1/5/6/10/11/20 个的列数、行数、均在屏内、互不重叠、最小尺寸）；攻击键断言（冷却拒绝、空挥不进冷却、咬中进入冷却、失控/冲撞拒绝、按钮位置不压技能）。
- 门禁四件套 + 三份报告 + `TASK_INDEX.md` / `引擎词总表.md` / `LEARNING_ROADMAP.md` / docx 收尾。

## 五、风险与回滚

- **4 列拥挤**：132px 宽按钮在手机上偏小；若 F5/手机可点击性不足，回滚到「最多 3 列 + 高度压缩更狠」或给按钮加长按放大。总开关式常量集中在文件顶部，回滚只调常量。
- **攻击键误触**：右手拇指区已有摇杆（换右手侧）与技能组，攻击键可能抢占；回滚把按钮缩到 80×80、或移到技能组正下方。
- **空挥不进冷却**：可能被当作「无消耗探刀」，但空挥本身有动画与音效成本，F5 再评估；若滥用改成空挥进 0.3 秒小冷却。
- **与 TASK-026 咬击改动重叠**：026 改 `_chang_shi_yao_ji` 内部结算（经验/减免），029 只加外层入口；两包串行（026 → 027 → 028 → 029），029 在 026 落地后再开工，冲突面最小。
