## 一、任务目标

项目原来的成长线是「吃鱼涨经验 → 升级 → 抽 3 张 buff 卡」。5 张旧卡（迅捷/贪食/活力/睿智/磁吸）与「吃谁得谁」的鱼类能力设计冲突，本任务把旧卡整体退役，落地能力系统：

1. **能力获取**：升级时三选一能力，不再是旧 buff 卡。
2. **能力来源**：每种有特点的鱼被吞后提供对应能力；本局吃得最多的能力有 50% 概率出现在升级候选中。
3. **技能操作**：主动技能只能装 1 个，由右下角按钮释放，按钮显示名称与冷却；被动可叠层。
4. **NPC 同样消费能力**：同一份 `NengLi` 数据，玩家拿主值，NPC 拿 `npc_shu_zhi` / `npc_jian_ge`。

## 三、关键规则

### 能力获取与账本

- `ZhangBen.xuan_neng_li(neng)`：主动替换唯一槽并广播；被动层数 +1 并广播；每次选择都写入 `yi_xuan_neng_li`。
- `ZhangBen.ji_chi_yu(neng)`：只在消化完成时调用；平局保留先到者。
- `chong_zhi()` 清空主动、被动层数、获得历史、食谱、最常吃 id。
- 三选一排除当前已装备的主动；被动可重复出现用于叠层。
- 50% 强制项只应在本局最常吃的能力仍在候选池中时生效；不在池中时不能假装锁定。

### 玩家能力

- `Yu.shi_fang_zhu_dong()` 是唯一释放入口：无主动 / 冷却中 / 失控 / 施放中都返回 `false`，成功才进入冷却。
- 放电：半径内所有 `yu_npc` 叠电麻条；不电自己。
- 毒棘：任何来源咬玩家或撞玩家，只要来源有 `jia_du_yun`，都反毒；反毒在扣血之前，死亡也能反毒。
- 极速：0.8 秒目标速度 ×2，转向仍按体型。
- 冲撞：0.45 秒直线位移，命中伤害 ×2，不整吞；同一目标一次；期间屏蔽嘴圈吞与自动咬；命中靠 `yao_qu.get_overlapping_areas()`，测试需等物理帧刷新。
- 潜伏：隐身 2 秒，NPC 索敌跳过；下一口伤害 ×2；咬中/受伤/到期破隐；切换主动也破隐。
- 切换主动：清掉极速/冲撞/潜伏状态，冷却归零。

### NPC 能力

- 电鳐：每 `npc_jian_ge` 秒放电，半径 `ban_jing`，数值 `npc_zhi()`。
- 蓑鲉：被咬或吞它的鱼都叠毒晕，数值 `npc_zhi()`。
- 旗鱼：目标距离在咬击距离与 260px 之间时启动 0.8 秒突进，冷却 6 秒。
- 金枪鱼：目标 240px 内启动 0.45 秒冲撞，伤害 ×2，每目标一次，冷却 7 秒。
- 巨口鱼：目标在感知内且不在咬击距离时潜伏 2 秒，下一口 ×2，冷却 8 秒。
- 失控打断突进/冲撞/潜伏；玩家潜伏时普通鱼放弃目标，首领清追击计时。
