# 学习记录 — TASK-024

## 本节要学的引擎概念

- **鸭子类型（duck typing）**：不要求对象是 `YuNpc`，只要它有同名方法（`shou_dao_ji_neng`、`jia_du_yun`…），`has_method` + `call` 就能用。船因此能复用整套技能系统。
- **节点组（group）**：`add_to_group(&"ji_qi_chuan")` 与 `get_nodes_in_group`。船单独成组，不混进 `yu_npc`，避免刷怪/吞噬把船当鱼。
- **单位换算**：鱼的伤害单位是「掉几级体型」；船的伤害单位是 HP。`JI_NENG_MEI_JI_HP` 是两者之间的汇率。
- **状态计时与抗性**：`_zhuang_tai_sheng_yu` 字典 + 每帧减 delta；抗性窗口防止多技能无限锁死。
- **自动探针**：无头模式真实跑一局，只能证明「机器人能通关」，不能代替真人手感。

## 引擎词表

| 词 | 含义 | 本任务用在哪 |
| --- | --- | --- |
| Duck typing / 鸭子类型 | 按行为而非类型判断对象能力 | 船实现 YuNpc 同名方法 |
| Group / 节点组 | 场景树里的轻量标签集合 | `ji_qi_chuan` 组 |
| `has_method` / `call` | 运行时按方法名检查与调用 | 技能扫描过滤船 |
| Delta | 上一帧到这一帧的秒数 | 状态/抗性倒计时 |
| DoT（Damage over Time） | 持续伤害 | 酸蚀每秒扣船 HP |
