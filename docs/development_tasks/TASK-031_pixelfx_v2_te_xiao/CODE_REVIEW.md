## 三、取舍记录

| 取舍 | 理由 | 代价 |
|---|---|---|
| **单档高清**（每套 1 张 128~160px，运行时缩放） | 用户拍板包体/内存优先；84 套合计 6.6MB | 极小体型下缩放后像素略软；实测可接受 |
| **同 id 不同色复用**（如 poof 底图 4 色、ricochet 2 色、crit-hit 2 色） | 收敛 pixelfx 出图与包体；颜色即语义 | 形状共享，辨识靠颜色；清单 §二已登记全部复用对 |
| **H10 桶眼鱼整组跳过** | 鱼种已退池（TASK-030），无接入点 | 文档 H10 章节不落地，已在清单注明 |
| **船无 `ti_chang`/`ti_gao` 用默认 100/80 尺度挂光环** | `ji_qi_chuan.gd` 非鱼体系，无体型方法 | 船体光环固定大小，与船体 300px 比例协调（F5 复核） |
| **`bo_ming` 不加 rotation 参数** | 旋转只是射线类少数调用点的需求，写进通用 API 增加参数面 | 射线类取返回值后自设 `fx.rotation = fang.angle()`（三星技能共 4 处） |
| **循环 + `chi_xu=0` 由调用方释放** | 图鉴预览需要无限循环 + 外部重播控制 | 调用方必须记住释放；目前仅图鉴一处使用该模式，`_qing_yu_lan_tai` 统一清 |
| **饕餮窗口用 meta 存节点 + 每帧跟随** | 窗口特效需跟玩家移动，但生命周期归模块 | 玩家死亡/换形态时依赖节点自毁兜底；已确认 `_geng_tao_tie` 先验 `is_instance_valid` |
| **疯狂（feng_kuang）无活来源仍烘** | 文档要求 6 色齐全，槽位保留 | 1 套资源 0 接入；`ZHUANG_TAI_KU` 已登记，未来接源即生效 |
