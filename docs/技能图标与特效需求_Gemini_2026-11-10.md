## 0. 一页速查（可直接复制）

**项目风格一句话**：PopCap 式明亮美式卡通——深蓝海水、粗深色描边、大色块平涂、大眼萌、高饱和鱼体、夸张剪影。

**主参考**：《Feeding Frenzy 2》（PopCap）、《捕鱼达人》、《植物大战僵尸》（怪诞形态）、《Insaniquarium! Deluxe》。

**主提示词（英文，单帧）**：

```
2D mobile game sprite, bright PopCap-style cartoon, thick dark navy outline,
flat cel shading with 3 tones, saturated colors, exaggerated cute silhouette,
big expressive eye, side view, head facing RIGHT, centered composition,
transparent background (true alpha), no ground shadow, no water splash,
no text, no watermark, no frame, no 3D render, no realistic texture, no pixel art.
Subject: <按条目替换>
```

**负面词**：

```
realistic, photorealistic, 3D render, glossy plastic, painterly, oil painting,
watercolor, soft airbrush, pixel art, low poly, sketch, lineart only,
complex scales texture, noisy detail, drop shadow, ground shadow, white background,
checkerboard background, text, logo, watermark, border, multiple fish, sprite sheet
```

**输出底线**：

1. 图标：`1024×1024 PNG`，真透明底；主体占画布 78–86%，四周留 ≥8% 透明边。
2. 特效：`1024×1024 PNG` 单帧，真透明底；4 帧同画布、同构图、同配色，只有动画元素变化。
3. 外轮廓 14–18px（1024 画布），最终缩到游戏尺寸后约 1.5–2px；描边不用纯黑，用同色相压暗 35–45%。
4. 每个材质最多 3 个色阶：底色 + 暗部 + 硬边高光；禁止细密鳞片、皮肤噪点、写实反光。
5. 不画投影、环境雾、水花（特效条目点名要水花时才画）；不画文字、数字、UI 边框。
6. 鱼/光束一律**朝右**；特效光束在画布中横向铺开，运行时由代码旋转。
7. 同一组 4 帧：身体中心/光束起点位移 ≤2% 画布，不得换姿势、换颜色、换视角。

## 2. 统一技术规范（Gemini 必须按此输出）

### 2.1 图标

| 项 | 规格 |
|---|---|
| 画布 | 1024×1024 PNG，RGBA 真透明 |
| 主体占比 | 78–86%，居中；四周 ≥8% 透明边 |
| 最终入库 | 我方缩到 128×128，UI 内显示 44×44 |
| 构图 | **一个主主体 + 最多 3 个辅助符号**；不要画成一整条鱼+背景场景 |
| 描边 | 14–18px 深海军蓝/同色相压暗；发光核心加 1–2px 白/浅色内描边 |
| 可读性 | 缩到 44×44 仍能一眼认出主动/被动类型 |
| 文字 | 禁止任何文字、数字、字母、UI 边框、技能名 |
| 朝向 | 鱼头朝右；武器/光束朝右；爆炸/护盾居中对称 |

**图标颜色语义**（只用于点缀，不整体染色）：
- 主动技能：金橙 `#FFB43C` 点缀；
- 被动技能：青绿 `#6FE3D0` 点缀；
- 进化专属：紫 `#B45CFF` 点缀；
- 危险/毒：毒绿 `#B7F05A` + 紫 `#B45CFF`；
- 电系：青蓝 `#4AD8D0` + 白 `#D8FFF7`；
- 深渊/鲸鲨：墨蓝 `#101A26` + 星蓝 `#6A7BFF`。

### 2.2 特效（4 帧）

| 项 | 规格 |
|---|---|
| 画布 | 1024×1024 PNG 单帧 ×4，RGBA 真透明 |
| 帧序 | f1 出现/蓄力 → f2 扩张 → f3 峰值/命中 → f4 消散/回收 |
| 最终入库 | 我方拼成横排 4 帧条，高 208–256px；播放 12 fps，动画名 `bao`，`loop=0` |
| 常驻光环 | 若条目写“常驻”，4 帧循环，播放 8 fps，`loop=1`，首尾帧必须能无缝衔接 |
| 锚点 | 光束/冲刺类以画布中心为锚点，左右各留 ≥10% 空白；运行时按朝向旋转 |
| 叠加 | 发光类默认加色混合（additive）；请把背景做成纯透明，不要用黑底“假发光” |
| 颜色 | 亮色核心 + 深色外描边；在深蓝海水背景上必须能读清 |
| 禁止 | 整屏渐白、镜头光晕、文字数字、UI 边框、多组特效拼在一张图 |

**4 帧硬规则（P1、P1.5 新做组、P2 全部适用）**：
- 帧序固定：f1 出现/蓄力 → f2 扩张 → f3 峰值/命中 → f4 消散/回收；同一组只做一个动作，不换姿势、不换视角、不换配色。
- 同组 4 帧必须同画布（1024×1024）、同构图、同锚点；主体中心/光束起点位移 ≤2% 画布。
- **真透明**：RGBA，背景 alpha 全 0；禁止白底、黑底、棋盘格、环境背景、地面投影。
- **朝右**：光束/鱼叉/冲刺的尖端朝右；爆炸/护盾/水花居中对称；运行时由代码旋转或翻转。
- **单主体**：一张图只放一组特效/一个主体；不画鱼或船本体（P1.5 新特效尤其注意），不把两个技能拼进一张图。
- **命名固定**：单帧 `<id>_zhen1.png` ~ `<id>_zhen4.png`；4 帧条由我方拼成 `<id>_4zhen.png`，Gemini 不拼图集。

> 已有 14 条特效沿用各自现有 `.tres` 的 fps（8/10/12），不重设；新做 39 条 + P1.5 新做 + P2 统一按 12 fps（常驻光环 8 fps）。P1.5 已有整船招式沿用现有速度（探照灯/船锚 4.44、炸弹 4.0、鱼叉 6.67 fps）。
