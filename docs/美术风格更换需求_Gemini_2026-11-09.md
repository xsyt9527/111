## 0. 一页速查（可直接复制）

**项目风格一句话**：PopCap 式明亮美式卡通——深蓝海水、粗深色描边、大色块平涂、大眼萌、高饱和鱼体、夸张剪影，手机上 108px 仍一眼可辨。

**主参考游戏**：《Feeding Frenzy 2》（PopCap）、《捕鱼达人》、《植物大战僵尸》（怪诞形态）、《Insaniquarium》。

## 1. 为什么换、换成什么（给决策人看的摘要）

### 1.1 现状问题

现有素材不是一套风格，而是三套混在一起：

- 大部分基础鱼：柔光厚涂、无描边（如凹凸蜗牛鱼、狮子鱼）；
- 机器船、珊瑚、气泡、部分鱼：粗描边卡通（如鲸鲨、机器船、珊瑚 4 帧）；
- 进化静态图、特效、图标：像素风或写实小图（如太岁肉灵芝兽、电特效）。

同一个画面里同时出现「厚涂鱼 + 描边船 + 像素特效」，所以看起来不统一。换风格的核心目标不是「更华丽」，而是**统一 + 手机小尺寸可读**。

### 1.2 风格对标（回答「像什么游戏」）

| 参考游戏 | 借什么 | 权重 |
|---|---|---|
| **《Feeding Frenzy 2: Shipwreck Showdown》**（PopCap） | 主风格：深蓝海水、粗描边、高饱和鱼、吃鱼玩法的剪影辨识度 | ★★★★★ 主参考 |
| **《捕鱼达人》** | 国内玩家熟悉的鱼种造型、高饱和配色、深海氛围；**不要**它的 3D 塑料光泽 | ★★★★ |
| **《植物大战僵尸》**（PopCap） | 进化后的怪诞形态：夸张轮廓、坏笑/獠牙，但仍然是「可爱的怪物」 | ★★★★ |
| **《Insaniquarium! Deluxe》**（PopCap） | 大眼萌、鱼鳍摆动方式、水族箱式热闹感 | ★★★ |
| **《潜水员戴夫》** | 只参考背景的层次与光束；**不采用像素画** | ★★ 仅背景参考 |
| 《Abzû》/《GRIS》 | 不采用：太柔、鱼在深色背景里辨识度差，不利于「吃/被吃」判读 | ✗ |
| 写实 3D 捕鱼手游 | 不采用：与现有 2D 纸片管线不兼容，动画成本高 | ✗ |
| 真像素风（Dave the Diver 全套） | 不采用：需要全部素材重画，AI 出帧一致性最差；现有「像素/经典2D」开关只是采样滤镜，不是真像素素材 | ✗ |

### 1.3 选定风格名

**「明亮描边卡通」（Bright Outlined Cartoon）**

一句话：像 PopCap 的 Feeding Frenzy 2 / 捕鱼达人，但更干净、更适合手机小屏。  
情绪：热闹、明亮、有点怪诞萌；进化形态可以变丑变凶，但始终是卡通怪物，不是写实恐怖。

## 2. 统一视觉规范（Style Bible）

### 2.1 线条

- 外轮廓：1024 画布上 **14–18px**；缩到游戏内 108px 后约 **1.5–2px**。
- 内部结构线：**6–8px**（鳍与身体分界、鳃线、嘴线），不要每条鳍刺都描边。
- 描边颜色 = 填充色同色相压暗 35–45%，**不用纯黑**。例：
  - 橙红鱼 `#FF6A3D` → 描边 `#8C2F16`
  - 青蓝鱼 `#4AD8D0` → 描边 `#1C6E6A`
  - 深紫鱼 `#5B4A86` → 描边 `#241B3D`
  - 深色/黑色鱼统一用深海墨蓝 `#101A26`
- 眼睛、獠牙、发光核心可以用近黑 `#0B1220`，形成最高对比点。
- 发光物（诱饵、电光、等离子）外圈再加一圈 **1–2px 的白/浅色内描边**，保证在深色背景上不糊。

### 2.2 上色

- 每个材质最多 **3 个色阶**：底色、暗部（压暗 15–20%）、高光（提亮 20–30%）。
- 暗部用硬边 + 2–3px 软过渡；高光用月牙形/椭圆硬边，一块主体 1–2 处。
- 允许沿身体方向的**轻微渐变**（明度变化 ≤8%），不允许跨全图的空气喷枪渐变。
- 鱼鳍：同色系提亮 15–25%；鳍膜 alpha 80–95%，不要羽毛状半透明边。
- 禁止：鳞片网格、皮肤噪点、写实反光、环境色反射、HDR 塑料高光。

### 2.3 光照与视角

- 统一光照：**左上主光，右下暗部**。所有素材同一方向，不能有的左上有的右上。
- 视角：**纯侧视**（2D 纸片），头朝右，尾朝左；只露一侧胸鳍和背鳍。
- 眼睛：占头长 22–28%，奶油白眼球 + 深墨蓝/黑瞳孔 + 1 个白色高光点（可加 1 个小副光点）。
- 表情：以眼形和嘴线表达，不画复杂拟人五官；坏笑、獠牙、怒眉可以有，但保持卡通。

### 2.4 比例与剪影

- 常规鱼：体长 : 体高 ≈ **2.2–3.2 : 1**。
- 细长鱼（剑鱼、旗鱼、电鳗）：**3.5–4.5 : 1**。
- 圆胖鱼（蜗牛鱼、河豚类）：**1.6–2.0 : 1**。
- 鲸鲨/首领：**2.6–3.6 : 1**，要明显更宽厚。
- 嘴在画面最右侧边缘，尾鳍在最左侧，**不能裁切**。
- 每种鱼必须有 1 个「108px 还能认出来」的剪影特征：大嘴、长吻、帆鳍、发光诱饵、透明头罩、毒棘、九尾等。
- 同一鱼种的 3 个进化形态，**保留该鱼种的基础身体轮廓**（例如都是长吻剑鱼型、都是大嘴巨口型），只在这个轮廓上做分支变化。

- 背景整体比鱼体**暗 20–30%，饱和度低 10–20%**，保证鱼是画面最亮、最饱和的东西。
- 背景近层岩石/珊瑚可以用粗描边；远层只用剪影，不描边，形成空气透视。
- 背景中心（玩家常活动的 1280×720 区域）要留大片开阔水，不能堆满高对比细节。

## 3. 技术输出规则（必须逐条满足）

### 3.1 画布与透明

- 单帧输出：**1024×1024 PNG**（背景图除外）。
- 主体占画布 78–86%，四周留 ≥8% 透明边；尾巴/长吻可以超出，但不能贴边裁切。
- 真透明背景（RGBA，alpha=0 为透明）。**不要**白底、黑底、棋盘格底。
- 如果 Gemini 不能输出真透明：改用**纯洋红 `#FF00FF` 平涂背景**，主体及描边上不能出现洋红反光；我方后期键色。
- 不要地面投影、环境雾、水花、气泡、速度线（特效条目单独规定）。

### 3.2 朝向

- **所有鱼：头朝右、尾朝左**（游戏内最终朝向）。
- 所有机器/道具：按条目指定朝向（机器船朝左，炮口/推进器在右侧；锚/爪朝下）。

### 3.3 帧间一致性（最重要）

- 同一素材的所有帧必须：同一画布、同一大小、同一位置、同一配色、同一光照。
- 身体中心位移 ≤2% 画布；只有尾巴、胸鳍、背鳍、嘴可以动。
- 不得换姿势、换表情、换颜色、换比例、换视角。
- 生成方式：先出第 1 帧（中性姿势），再把第 1 帧作为参考图，逐帧只修改指定部位；不要每帧重新描述整条鱼导致「每条都像不同鱼」。

### 3.4 最终入库尺寸（Gemini 不必直接出这个尺寸，我方会缩）

| 类别 | 游戏内尺寸 |
|---|---|
| 基础鱼 / 进化鱼 内容高 | 108px |
| 基础鱼 4 帧条 | 高 124–188px（含鳍），内容高 108 |
| 进化鱼 6 帧条 | 高 112px（内容 108 + 上下各 2px 透明边） |
| 攻击 4 帧条 | 高 256px |
| 特效 4 帧条 | 高 208–256px |
| 机器船 4 帧条 | 高 272px |
| 技能图标 | 128×128（UI 内显示 44×44） |
| 场景装饰 | 高 164–200px |
| 肉块 | 高 48px |
| 气泡 4 帧条 | 高 256px，4 格各 256×256 |
| 背景 | 4128×2304（16:9 整张关卡，非平铺） |

> 缩小由我方 Python 流水线统一完成，Gemini 只要保证「大图比例、留边、透明、帧一致」。

## 4. 动画帧规范

### 4.1 基础鱼游动 4 帧（所有 11 种基础鱼）

| 帧 | 尾巴 | 胸鳍 | 身体 |
|---|---|---|---|
| f1 | 水平居中 | 自然下垂 | 正中，基准姿势 |
| f2 | 上摆 12–15° | 前摆 8° | 上浮 1–2% |
| f3 | 水平居中 | 自然下垂 | 正中 |
| f4 | 下摆 12–15° | 后摆 8° | 下沉 1–2% |

循环顺序 f1→f2→f3→f4，播放速度约 8 fps（我方设置）。嘴保持微张/闭合一致，不逐帧变表情。

### 4.2 进化鱼游动 6 帧（所有 33 种进化形态）

| 帧 | 尾巴 | 附加 |
|---|---|---|
| f1 | 居中 | 基准 |
| f2 | 上摆 8° | 胸鳍前摆 5° |
| f3 | 上摆 16° | 背鳍/冠饰轻微上扬 |
| f4 | 居中 | 基准 |
| f5 | 下摆 8° | 胸鳍后摆 5° |
| f6 | 下摆 16° | 背鳍/冠饰轻微下压 |

播放速度约 10 fps（6 帧 ≈0.6 秒循环）。发光部件（诱饵、核心、电光）亮度保持恒定，不做逐帧闪烁（闪烁由游戏内代码做）。

### 4.3 攻击动作 4 帧（仅 5 种：电鳗/剑鱼/巨口鱼/旗鱼/狮子鱼）

| 帧 | 动作 |
|---|---|
| f1 | 蓄力：身体后缩 10%，嘴闭，鳍收紧 |
| f2 | 突进：身体前伸 15%，嘴张开 50%，眼睛盯住右前方 |
| f3 | 咬合/刺出：嘴全开或长吻完全前刺，獠牙可见，身体最大伸展 |
| f4 | 回收：嘴合上一半，身体回正，鳍放松 |

- 画布比游动帧更宽（长吻/大嘴要放得下），高度保持 256px 基准。
- 不画命中特效（特效单独素材）；可以画嘴部冲击形变，但不要速度线。

### 4.4 特效 4 帧（14 组）

统一节奏：f1 核心出现 → f2 扩张 → f3 峰值（最大最亮）→ f4 碎裂/消散。  
- 亮色核心 + 深色外描边，保证在深蓝背景上可读。
- 不要整屏渐白、不要镜头光晕、不要文字数字。

### 4.5 机器船 / 锚 / 爪 4 帧

- 整船：f1 基准 → f2 上浮 4px → f3 基准 → f4 下沉 4px；螺旋桨水花随帧变化，船体不变形。
- 船锚：f1 收起 → f2 下落 → f3 触底展开 → f4 稳定。
- 机械爪：f1 张开 → f2 合拢一半 → f3 全合 → f4 松开。
