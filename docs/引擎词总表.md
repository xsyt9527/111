## 项目级配置（project.godot）

| 引擎词 | 所属 | 释义 |
|---|---|---|
| `config/features` | application | 引擎特性标记（4.7 / Mobile 渲染），锁定引擎识别 |
| `window/stretch/mode="canvas_items"` | display | 窗口缩放模式：按画布元素缩放，适配不同分辨率 |
| `window/stretch/aspect="keep"` | display | 保持宽高比（横屏 16:9） |
| `emulate_touch_from_mouse` | input_devices | 鼠标模拟触摸：开发期 PC 上也能收到触摸事件 |
