# 深海食纪 — 引擎词总表

> 沿用金币项目惯例：按文件分类收录本项目用到的引擎词（API/概念/节点），
> 每课新增时更新。**写得出 = 真学会了。**

## 项目级配置（project.godot）

| 引擎词 | 所属 | 释义 |
|---|---|---|
| `config/features` | application | 引擎特性标记（4.7 / Mobile 渲染），锁定引擎识别 |
| `window/stretch/mode="canvas_items"` | display | 窗口缩放模式：按画布元素缩放，适配不同分辨率 |
| `window/stretch/aspect="keep"` | display | 保持宽高比（横屏 16:9） |
| `emulate_touch_from_mouse` | input_devices | 鼠标模拟触摸：开发期 PC 上也能收到触摸事件 |

## 第 1 课 · 玩家鱼游动（按文件分类）

### scripts/yu.gd（玩家鱼蓝图）

| 引擎词 | 释义 |
|---|---|
| `extends Node2D` | 继承 Node2D：有位置/旋转/缩放的 2D 节点 |
| `class_name Yu` | 注册全局类名，别的脚本可把类型写成 `Yu` 而不是 `Node2D` |
| `@export var yidong_sudu := 300.0` | 导出变量：出现在检查器里可直接调，`:=` 为类型推断 |
| `var mubiao_dian: Vector2` | 普通成员变量，不导出；由 Main 写入的游动目标点 |
| `_ready()` | 节点进入场景树后调用一次（捡金币第 1 课亲戚） |

### scripts/main.gd（主场景协调者）

| 引擎词 | 释义 |
|---|---|
| `_unhandled_input(event)` | 未被 UI/其他节点消费的输入事件会送到这里（事件驱动，不代表每帧调用） |
| `InputEventScreenTouch` | 触摸按下/松开事件；`event.pressed` 区分按下（true）与松开（false） |
| `InputEventScreenDrag` | 触摸按住期间的移动事件（**没有** InputEventScreenMotion 这个类型——引擎会解析报错） |
| `event.position` | 事件的屏幕坐标（本场景无相机，等于世界坐标） |
| `@onready var yu: Yu = $Yu` | 场景树就绪时取子节点引用，带类型标注 |

### scenes/（场景与主场景）

| 引擎词 | 释义 |
|---|---|
| `run/main_scene` | project.godot 里的运行入口场景；F5 与导出的 APK 都从这里启动 |
| `instance=ExtResource(...)` | .tscn 中把另一个场景实例化后挂进本场景（场景内静态实例化） |
| `scale = Vector2(20, 11.25)` | 精灵缩放：64×64 海床贴图放大到 1280×720 铺满 |

## 第 2 课 · 鱼群生成（按文件分类）

### scripts/yu_npc.gd（NPC 鱼蓝图）

| 引擎词 | 释义 |
|---|---|
| `class_name YuNpc` | 注册全局类名，生成器里可写 `var xin_yu: YuNpc` |
| `@export var tie_tu_shu_zu: Array[Texture2D]` | 类型化数组导出：检查器里可拖入多张贴图，限制元素类型 |
| `randf_range(a, b)` | 返回 [a, b] 之间的随机小数；Godot 4 启动自动播种，无需 randomize() |
| `pick_random()` | Array 方法：随机返回一个元素 |
| `Vector2.ONE` | 常量 (1, 1)；`Vector2.ONE * tixing` 表示等比缩放 |
| `get_viewport_rect().size` | 当前视口（屏幕）尺寸；比写死 1280×720 更稳 |
| `queue_free()` | 请求在当前帧末尾释放节点（从场景树移除并回收内存） |
| `scale` / `$Sprite2D.flip_h` | 节点缩放；精灵水平翻转，让鱼头朝前进方向 |

### scripts/yu_qun.gd（鱼群生成器）

| 引擎词 | 释义 |
|---|---|
| `preload("res://...")` | 编译期加载场景资源，得到 PackedScene |
| `YU_NPC_CHANGJING.instantiate()` | 由 PackedScene 创建一份运行时实例（还没进树） |
| `add_child(xin_yu)` | 把实例挂成当前节点子节点；此时才触发它的 `_ready()` |
| `Timer`（节点） | 定时器节点：到点发出 `timeout` 信号 |
| `$Dingshi.timeout.connect(callable)` | 代码连接信号：到点调用指定方法 |
| `wait_time` | Timer 等待时长（秒） |
| `one_shot = true` | 只响一次；每次需要手动 `start()` 重新计时 |
| `start()` | 启动/重启计时器 |
| `get_children()` | 返回全部直接子节点；配合 `is YuNpc` 精确计数 |
| `is`（类型判断） | `zi is YuNpc` 判断节点是否为该类实例 |

### scenes/（场景与装配）

| 引擎词 | 释义 |
|---|---|
| `[node name="Dingshi" type="Timer" parent="YuQun"]` | .tscn 中声明 Timer 子节点及其属性 |
| `one_shot = true`（场景文件） | 场景保存的 Timer 属性，与检查器一致 |
| `ext_resource type="Script"` | 场景引用外部脚本资源 |

### 概念小结

| 概念 | 一句话 |
|---|---|
| 随机间隔生成 | 每次超时后用 `randf_range` 重设 `wait_time`，鱼群密度有起伏 |
| 生成器 / 蓝图分工 | 生成器管何时、从哪、多快；NPC 管长相、移动与自我回收 |
| 屏幕外回收 | 动态节点用 `queue_free()` 释放，否则节点越积越多 |

## 第 3 课 · 大吃小判定（按文件分类）

### scripts/yu.gd（判定与受伤）

| 引擎词 | 释义 |
|---|---|
| `Area2D` | 不可见的物理检测区：别的区域进入时发信号；只检测不推挤 |
| `collision_layer` | 「我是什么」——我挂的牌子，别人按层找到我（1=玩家，2=鱼群） |
| `collision_mask` | 「我监视谁」——勾了谁的层，谁进我的圈我就发信号 |
| `area_entered(area: Area2D)` | Area2D 的检测信号：参数就是闯进来的那个 Area2D |
| `qu.get_parent() as YuNpc` | 取检测区的宿主节点；`as` 类型转换，转不成得 null |
| `modulate` | 节点颜色调制（乘在贴图上）：受伤闪红、恢复都用它 |
| `Color(1.0, 0.4, 0.4)` / `Color.WHITE` | RGB 颜色值；WHITE 常量 = 原色 |

### scenes/（检测区装配）

| 引擎词 | 释义 |
|---|---|
| `CollisionShape2D` | 给 Area2D 定形状与大小的子节点，无形状会警告 |
| `sub_resource type="CircleShape2D"` | .tscn 内嵌形状资源；`radius = 22.0` 是圆半径 |
| 判定圈随 scale 缩放 | NPC 根节点 `scale = tixing`，子节点 CollisionShape2D 自动跟着变大变小（白送） |
| `WudiDingshi (Timer, one_shot)` | 无敌计时器：复用第 2 课 Timer 模式做受伤保护 |
| 多形状合并成一个区 | 一个 Area2D 可挂多个 CollisionShape2D，但形状**合并**为一个检测区、一个信号，分不清触发来源 |
| 分行为须分 Area2D | 想"两个范围、两种反应"（如吃区大/伤区小）要两个 Area2D 各配形状、各连信号——第 7 课磁吸 buff 的骨架 |

### 概念小结

| 概念 | 一句话 |
|---|---|
| 单向检测防重复 | 只有玩家 mask=2 在监视，NPC mask=0 沉默——一次碰撞只发一次信号 |
| 大吃小规则 | `tixing > tixing` 严格大于才吃得下；相等算撞大鱼 |
| 无敌帧 | 受伤后 1 秒不重复受伤（Timer + wudi 标记），期间仍能吃小鱼 |
| 挂钩点思维 | `bei_chi()` / `_shoushang()` 先挖好入口，第 5/8 课直接在入口记账 |

## 第 4 课 · 数据驱动鱼种（按文件分类）

### scripts/yu_zhong.gd（鱼种模具）

| 引擎词 | 释义 |
|---|---|
| `extends Resource` | 继承资源类：纯数据容器，不是场景节点、不进场景树 |
| `class_name YuZhong` | 注册全局类名后，.tres 与类型化数组才能引用它 |
| `@export var tie_tu: Texture2D` | Resource 也能 @export：字段出现在检查器里可直接填 |
| `resource_path` | Resource 的 `res://` 路径（探针里用来核对抽中哪种鱼） |

### data/yuzhong/*.tres（鱼种数据）

| 引擎词 | 释义 |
|---|---|
| `.tres` 资源文件 | 填好数据的 Resource 实例存成磁盘文件；双击检查器可编辑 |
| `script_class="YuZhong"` | .tres 头部标记：这份数据用哪个模具解析 |
| `[ext_resource type="Script" uid=...]` | .tres 引用模具脚本与贴图；uid 是资源的稳定身份证 |
| `load_steps` | 资源头部记录的加载步骤数（编辑器自动维护） |

### scripts/yu_qun.gd（注册表）

| 引擎词 | 释义 |
|---|---|
| `Array[YuZhong]` | 类型化资源数组：检查器拖入 .tres，元素类型受限 |
| `pick_random()`（资源数组） | 注册表抽取：随机返回一个鱼种数据 |
| Create New → Resource… | 编辑器新建资源入口：选模具 → 检查器填数 → 存成 .tres |

### 概念小结

| 概念 | 一句话 |
|---|---|
| Resource 三分工 | 脚本=模具（定结构）、.tres=数据（存数值）、检查器=填表（改数值） |
| 注册表模式 | 加新鱼零代码：新建 .tres 填字段 + 拖进数组（第 6 课强化卡复用此套路） |
| 资源注入顺序 | 生成器 add_child 前赋 yu_zhong，_ready 消费——数据先于生命周期 |
| 数据与代码分离 | 数值全在数据文件里改，代码只认结构——策划改表不动程序员代码 |

## 第 5 课 · 经验与成长（按文件分类）

### project.godot（Autoload 注册）

| 引擎词 | 释义 |
|---|---|
| `[autoload]` 段 | 项目设置里的全局单例注册表：名字 = 脚本路径 |
| `ZhangBen="*res://..."` | 星号=启用；名字从此是全局标识，任意脚本按名直呼 |
| 项目设置 → Autoload 页 | 编辑器查看/增删单例的界面（学生 inspection 实操过） |

### scripts/zhang_ben.gd（Autoload 账本）

| 引擎词 | 释义 |
|---|---|
| Autoload 全局单例 | 引擎启动即创建、挂在 root 与场景平级、切场景不销毁——比一切场景 _ready 都早就绪 |
| `signal jing_yan_bian_hua(jy, yz)` | 信号带参数广播：监听方回调签名必须一致 |
| `signal sheng_ji(xin_deng_ji)` | 一源多听：玩家、UI、（第 6 课）弹窗各自 connect 互不干扰 |
| `SHENG_JI_YUZHI[-1]` | 常量数组最后一项：满级封顶用 |

### scripts/yu.gd（信号监听）

| 引擎词 | 释义 |
|---|---|
| `ZhangBen.sheng_ji.connect(_on_sheng_ji)` | 连接 Autoload 信号：写在 _ready，Autoload 先就绪无窗口期 |
| `scale = Vector2.ONE * tixing` | 根节点缩放连带子节点：判定圈白送变大（第 3 课机制的消费） |

### scenes/Main.tscn + jing_yan_ui.gd（经验条 UI）

| 引擎词 | 释义 |
|---|---|
| `CanvasLayer` | 独立画布层：树上是孩子（随场景生灭）、画布上独立（不继承 Node2D 变换，钉死屏幕） |
| `ProgressBar` | 进度条控件：max_value/value 两值驱动，适合经验/血量 |
| `offset_left/top/right/bottom` | Control 控件的矩形四边（锚点为 0 时即屏幕像素坐标） |
| `Label` | 文本控件；`"Lv.%d" % deng_ji` 是格式化字符串写法 |
| `@onready var x = $子节点` | _ready 时才取节点引用（UI 脚本标准开头） |

### 概念小结

| 概念 | 一句话 |
|---|---|
| 账本模式 | 唯一所有者（数值只有账本能写）+ 唯一入口 + 信号广播——账本不认识任何场景节点 |
| 本级经验制 | 升级扣除已用阈值从零重攒（jing_yan -= yuzhi），不是累计总分 |
| 生命周期 vs 渲染 | 挂在哪=跟谁生灭（Autoload 跨场景/UI 随场景）；怎么画=坐标继承谁（CanvasLayer 切断继承） |
| 信号解耦 | 广播方不知道谁在听——第 6 课弹窗只需自己 connect，账本零改动 |
